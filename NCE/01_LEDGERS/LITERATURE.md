# Registre bibliographique

Toutes les entrées ci-dessous sont citées **de mémoire**. Statut : **à vérifier sur source primaire (audit L-01)**. Les volumes et pages doivent être contrôlés. Aucune entrée n'est inventée, mais une erreur de détail reste possible tant que l'audit n'est pas fait.

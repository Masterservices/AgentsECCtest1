## Chapitre 3 — Codage de source : compression et borne de Shannon

Une traduction, dans le vocabulaire de ce livre, est un morphisme entre deux façons de représenter la même chose, assorti d'un budget de ressources. Le chapitre précédent a mesuré ce que la traduction *fait perdre* en information ; celui-ci mesure ce qu'elle *coûte en place*. La traduction étudiée est la plus élémentaire de toutes : « source → bits ». Une source produit des symboles ; un encodeur les traduit en suites binaires ; un décodeur reconstruit les symboles. La ressource comptée est la longueur de description, en bits par symbole.

Le résultat central est d'une netteté rare : ce coût admet un plancher exact, l'entropie $H(X)$, et ce plancher est approchable d'aussi près qu'on veut. Ni plus bas, ni beaucoup mieux. Je vais établir ce résultat en cinq étapes, chacune avec son statut : l'inégalité de Kraft (PROUVÉ, preuve complète), la borne $L \ge H(X)$ (PROUVÉ, preuve complète), l'optimalité du codage de Huffman (CONNU, idée de preuve), la typicité (CONNU pour la loi des grands nombres, PROUVÉ pour les cardinalités), le théorème de Shannon (PROUVÉ, la partie directe étant démontrée ici en entier). La dernière section replace ce plancher dans le registre général des traductions : ce qu'un changement de modèle peut gagner, ce qu'il ne peut jamais gagner, et ce que le dictionnaire lui-même coûte.

Références mobilisées : Shannon 1948 ; Cover et Thomas 1991 ; Li et Vitányi 1993 ; Landauer 1961 en anticipation du chapitre 11.

### 3.1 Codes préfixes et inégalité de Kraft

Fixons un alphabet source $\mathcal{X} = \{a_1,\dots,a_m\}$ et un **code** $C : \mathcal{X} \to \{0,1\}^{*}$, de longueurs $\ell_i = |C(a_i)|$. L'extension aux messages est la concaténation : $C^{*}(x_1\cdots x_n) = C(x_1)\cdots C(x_n)$. Le code est *non singulier* si $C$ est injective ; il est *uniquement décodable* si $C^{*}$ est injective ; il est *préfixe* si aucun mot de code n'est préfixe d'un autre. Un code préfixe se décode à la volée, sans regarder le futur : c'est une contrainte de traduction en temps réel, pas seulement en espace.

**F3.1 — Inégalité de Kraft.**
$$\sum_{i=1}^{m} 2^{-\ell_i} \;\le\; 1$$
*En mots :* les « poids » $2^{-\ell_i}$ des mots d'un code préfixe binaire tiennent dans une unité. Réciproquement, toute famille de longueurs vérifiant cette inégalité est réalisable par un code préfixe. *Conditions :* alphabet fini, code binaire préfixe (sens direct) ; longueurs entières positives (réciproque). *Statut :* PROUVÉ. *Exemple :* longueurs $(1,2,3,3)$ : $0{,}5 + 0{,}25 + 0{,}125 + 0{,}125 = 1$, exactement saturé. Longueurs $(1,1,2)$ : $0{,}5+0{,}5+0{,}25 = 1{,}25 > 1$ : aucun code préfixe, et même aucun code uniquement décodable, ne peut avoir ces longueurs.

*Preuve complète (sens direct).* Plaçons les mots dans l'arbre binaire infini : un mot de longueur $\ell_i$ est un nœud à profondeur $\ell_i$, et il domine exactement $2^{\ell_{\max}-\ell_i}$ feuilles à la profondeur $\ell_{\max} = \max_i \ell_i$. La condition préfixe dit que ces ensembles de feuilles sont deux à deux disjoints. Leur réunion est incluse dans les $2^{\ell_{\max}}$ feuilles disponibles, d'où
$$\sum_{i=1}^{m} 2^{\ell_{\max}-\ell_i} \le 2^{\ell_{\max}},$$
et l'on divise par $2^{\ell_{\max}}$. $\square$

*Preuve complète (réciproque).* Ordonnons $\ell_1 \le \dots \le \ell_m$ et posons $w_i = \sum_{j<i} 2^{-\ell_j}$. Comme $\ell_j \le \ell_i$ pour $j<i$, le nombre $2^{\ell_i} w_i$ est entier : $w_i$ s'écrit donc en binaire avec exactement $\ell_i$ chiffres après la virgule, ce qui définit le mot $C(a_i)$. Les intervalles dyadiques $[w_i,\ w_i + 2^{-\ell_i})$ sont consécutifs, disjoints, et contenus dans $[0,1)$ puisque $\sum_i 2^{-\ell_i}\le 1$. Or un mot $u$ est préfixe d'un mot $v$ si et seulement si l'intervalle dyadique de $v$ est inclus dans celui de $u$ ; la disjonction interdit cette inclusion. $\square$

*Exemple de la construction :* longueurs $(1,2,3,3)$, sommes partielles $0\ ;\ 0{,}5\ ;\ 0{,}75\ ;\ 0{,}875$, écritures binaires $0{,}0\ ;\ 0{,}10\ ;\ 0{,}110\ ;\ 0{,}111$, code $\{0,\,10,\,110,\,111\}$ : préfixe, et Kraft saturée.

**F3.2 — Inégalité de McMillan (codes uniquement décodables).**
$$\Big(\sum_{i=1}^{m} 2^{-\ell_i}\Big)^{k} \;\le\; k\,\ell_{\max} \qquad \text{pour tout } k \ge 1$$
*En mots :* la même contrainte de poids vaut pour la classe plus large des codes uniquement décodables, ce qui montre que la liberté de ne pas être préfixe n'achète aucune longueur. *Conditions :* code uniquement décodable, $k$ entier quelconque. *Statut :* PROUVÉ (preuve ci-dessous ; résultat classique exposé chez Cover et Thomas 1991). *Exemple :* trois mots de longueur $1$ donneraient $S = 1{,}5$ et $S^{3} = 3{,}375$, alors que $k\,\ell_{\max} = 3$ : contradiction à $k=3$, donc un tel code n'existe pas.

*Preuve complète.* Posons $S = \sum_i 2^{-\ell_i}$. En développant la puissance $k$-ième,
$$S^{k} = \sum_{i_1,\dots,i_k} 2^{-(\ell_{i_1}+\dots+\ell_{i_k})} = \sum_{t=k}^{k\ell_{\max}} N_k(t)\, 2^{-t},$$
où $N_k(t)$ compte les $k$-uplets dont la concaténation a longueur $t$. L'unique décodabilité impose que ces concaténations soient toutes distinctes, donc $N_k(t) \le 2^{t}$. Ainsi $S^{k} \le k\ell_{\max} - k + 1 \le k\ell_{\max}$, puis $S \le (k\ell_{\max})^{1/k} \to 1$ quand $k \to \infty$. $\square$

Conséquence pour notre registre : **la contrainte de Kraft est la contrainte informationnelle de la traduction « symboles → bits »**, indépendante du modèle d'encodage choisi. Elle réapparaîtra au chapitre 5 comme propriété de la complexité de Kolmogorov.

### 3.2 Longueur moyenne d'un code et borne $L \ge H(X)$

**F3.3 — Longueur moyenne.**
$$L(C) \;=\; \sum_{i=1}^{m} p_i\,\ell_i$$
*En mots :* le coût moyen de la traduction, en bits par symbole. *Conditions :* source de loi $p$ connue, code uniquement décodable. *Statut :* PROUVÉ (définition). *Exemple :* $p = (0{,}5\ ;\ 0{,}25\ ;\ 0{,}125\ ;\ 0{,}125)$ et $\ell = (1,2,3,3)$ : $L = 0{,}5 + 0{,}5 + 0{,}375 + 0{,}375 = 1{,}75$.

**F3.4 — Entropie de la source (rappel du chapitre 1).**
$$H(X) \;=\; -\sum_{i=1}^{m} p_i \log_2 p_i$$
*En mots :* l'incertitude moyenne, en bits, avec la convention $0\log_2 0 = 0$. *Conditions :* alphabet fini, logarithme en base 2. *Statut :* PROUVÉ (définition, Shannon 1948). *Exemple :* pour la loi ci-dessus, $H = 0{,}5\times 1 + 0{,}25\times 2 + 2\times(0{,}125\times 3) = 0{,}5+0{,}5+0{,}75 = 1{,}75$ : le code atteint exactement l'entropie.

**Théorème (borne inférieure).** Pour tout code uniquement décodable, $L(C) \ge H(X)$, avec égalité si et seulement si $p_i = 2^{-\ell_i}$ pour tout $i$. Statut : PROUVÉ.

*Preuve complète.* Par l'inégalité $\ln x \le x-1$ (égalité ssi $x=1$), et avec $K = \sum_i 2^{-\ell_i} \le 1$ (F3.2) :
$$H(X) - L(C) = \sum_i p_i \log_2 \frac{2^{-\ell_i}}{p_i} \le \frac{1}{\ln 2}\sum_i p_i\Big(\frac{2^{-\ell_i}}{p_i} - 1\Big) = \frac{K-1}{\ln 2} \le 0.$$
L'égalité exige $K=1$ et $2^{-\ell_i}/p_i = 1$ pour tout $i$. $\square$

**F3.5 — Décomposition exacte de l'excédent.**
$$L(C) - H(X) \;=\; D(p\,\|\,q) \;+\; \log_2\frac{1}{K}, \qquad q_i = \frac{2^{-\ell_i}}{K},\quad K=\sum_i 2^{-\ell_i}$$
*En mots :* le surcoût se sépare en deux pertes distinctes — un *désaccord* entre la loi réelle et la loi implicite du code, et un *gaspillage* de l'espace de Kraft non rempli. *Conditions :* $p_i>0$, code uniquement décodable, $D$ la divergence de Kullback-Leibler en base 2. *Statut :* PROUVÉ (identité algébrique, les deux termes étant $\ge 0$). *Exemple :* $p=(0{,}4\ ;\ 0{,}2\ ;\ 0{,}2\ ;\ 0{,}1\ ;\ 0{,}1)$, code de Shannon $\ell=(2,3,3,4,4)$ (voir F3.6). Alors $K = 0{,}25+0{,}125+0{,}125+0{,}0625+0{,}0625 = 0{,}625$, donc $q = (0{,}4\ ;\ 0{,}2\ ;\ 0{,}2\ ;\ 0{,}1\ ;\ 0{,}1) = p$ et $D(p\|q)=0$. Tout l'excédent vient du gaspillage : $\log_2(1/0{,}625) = \log_2 1{,}6 = 0{,}6781$, et l'on vérifie $L - H = 2{,}8 - 2{,}1219 = 0{,}6781$.

**F3.6 — Code de Shannon et borne supérieure.**
$$\ell_i = \Big\lceil \log_2 \frac{1}{p_i}\Big\rceil \quad\Longrightarrow\quad H(X) \le L(C) < H(X) + 1$$
*En mots :* arrondir l'information propre de chaque symbole suffit à construire un code préfixe, et coûte au plus un bit de trop par symbole. *Conditions :* $p_i>0$, alphabet fini. *Statut :* PROUVÉ. *Exemple :* $p=(0{,}4\ ;\ 0{,}2\ ;\ 0{,}2\ ;\ 0{,}1\ ;\ 0{,}1)$ donne $\log_2(1/p) = (1{,}3219\ ;\ 2{,}3219\ ;\ 2{,}3219\ ;\ 3{,}3219\ ;\ 3{,}3219)$, arrondis $(2,3,3,4,4)$, puis $L = 0{,}8+0{,}6+0{,}6+0{,}4+0{,}4 = 2{,}8$, à comparer à $H = 2{,}1219$ et $H+1 = 3{,}1219$.

*Preuve complète.* Par définition de l'arrondi, $\log_2(1/p_i) \le \ell_i < \log_2(1/p_i)+1$ ; en multipliant par $p_i$ et en sommant, $H \le L < H+1$. De plus $2^{-\ell_i}\le p_i$, donc $K \le 1$ : la réciproque de Kraft (F3.1) fournit le code préfixe. $\square$

Ce « bit de trop » est la première fissure : il est *par symbole*. Si l'on traduit par blocs, on le paiera par bloc, donc plus par symbole. C'est toute la stratégie du théorème de Shannon.

### 3.3 Codage de Huffman : optimalité pour une distribution fixée

L'algorithme est glouton et se décrit en une phrase : répéter « fusionner les deux plus petites probabilités en un nœud de probabilité somme » jusqu'à obtenir la racine ; la longueur d'un symbole est sa profondeur dans l'arbre. Statut de l'optimalité : CONNU (exposé chez Cover et Thomas 1991). *Idée de preuve :* dans un code préfixe optimal, les deux symboles les moins probables peuvent être supposés frères à profondeur maximale (sinon on échange les mots sans augmenter $L$) ; les fusionner réduit le problème à $m-1$ symboles, et une récurrence conclut. Je ne reproduis pas la récurrence en entier.

*Exemple détaillé,* $p = (0{,}4\ ;\ 0{,}2\ ;\ 0{,}2\ ;\ 0{,}1\ ;\ 0{,}1)$ pour $(a,b,c,d,e)$ :
1. $d+e = 0{,}2$ ; reste $(a\ 0{,}4\ ;\ b\ 0{,}2\ ;\ c\ 0{,}2\ ;\ de\ 0{,}2)$.
2. $b+c = 0{,}4$ ; reste $(a\ 0{,}4\ ;\ bc\ 0{,}4\ ;\ de\ 0{,}2)$.
3. $de + a = 0{,}6$ ; reste $(bc\ 0{,}4\ ;\ ade\ 0{,}6)$.
4. Racine. Mots : $b=00$, $c=01$, $a=10$, $d=110$, $e=111$.

**F3.7 — Optimalité et encadrement de Huffman.**
$$H(X) \;\le\; L_{\mathrm{Huff}} \;=\; \min_{C\ \text{préfixe}} L(C) \;<\; H(X)+1$$
*En mots :* Huffman est le meilleur code préfixe symbole par symbole pour une loi fixée, et son surcoût reste sous un bit. *Conditions :* loi connue et fixe, un mot par symbole, décodage sans erreur. *Statut :* CONNU pour la minimalité, PROUVÉ pour l'encadrement (F3.3–F3.6). *Exemple :* $L = 0{,}4\times2 + 0{,}2\times2 + 0{,}2\times2 + 0{,}1\times3 + 0{,}1\times3 = 0{,}8+0{,}4+0{,}4+0{,}3+0{,}3 = 2{,}2$. Contre $3$ bits pour le code fixe : gain de $0{,}8$ bit, soit $26{,}7\,\%$. Excédent sur l'entropie : $2{,}2 - 2{,}1219 = 0{,}0781$ bit, soit $3{,}7\,\%$. Ici $K = 3\times 0{,}25 + 2\times 0{,}125 = 1$ : Kraft est saturée, et tout l'excédent est de la divergence $D(p\|q)$ avec $q=(0{,}25\ ;\ 0{,}25\ ;\ 0{,}25\ ;\ 0{,}125\ ;\ 0{,}125)$.

**F3.8 — Huffman par blocs.**
$$H(X) \;\le\; \frac{L_n^{*}}{n} \;<\; H(X) + \frac{1}{n}$$
*En mots :* en codant des blocs de $n$ symboles i.i.d. d'un seul coup, le surcoût par symbole devient $1/n$. *Conditions :* source i.i.d. de loi connue, $L_n^{*}$ la longueur moyenne optimale sur $\mathcal{X}^n$ (dont l'entropie vaut $nH(X)$). *Statut :* PROUVÉ, en appliquant F3.7 à la source-bloc. *Exemple :* Bernoulli $p=0{,}9$, $H = 0{,}9\times 0{,}1520 + 0{,}1\times 3{,}3219 = 0{,}4690$. Blocs de $2$ : probabilités $(0{,}81\ ;\ 0{,}09\ ;\ 0{,}09\ ;\ 0{,}01)$ ; Huffman donne les longueurs $(1,2,3,3)$, d'où $L_2 = 0{,}81 + 0{,}18 + 0{,}27 + 0{,}03 = 1{,}29$ bit par bloc, soit $0{,}645$ bit par symbole — contre $1$ bit sans codage. L'encadrement prédit $0{,}4690 \le 0{,}645 < 0{,}9690$ : vérifié.

Le prix est ailleurs : l'alphabet-bloc a $m^n$ éléments. La ressource *espace de description* a été échangée contre la ressource *temps et mémoire*. C'est un motif récurrent du livre.

### 3.4 Codage par blocs et typicité

**F3.9 — Propriété d'équipartition asymptotique (AEP).**
$$-\frac{1}{n}\log_2 p(X_1,\dots,X_n) \;\xrightarrow[n\to\infty]{\ \mathbb{P}\ }\; H(X)$$
*En mots :* la « surprise par symbole » d'un long tirage i.i.d. se concentre autour de l'entropie. *Conditions :* source i.i.d., alphabet fini (variance finie). *Statut :* CONNU — c'est la loi des grands nombres appliquée aux variables i.i.d. $-\log_2 p(X_i)$ (Shannon 1948 ; Cover et Thomas 1991). *Exemple :* Bernoulli $p=0{,}6$, $n=100$, tirage à $60$ uns : $-\frac{1}{100}\log_2 p = 0{,}6\times 0{,}7370 + 0{,}4\times 1{,}3219 = 0{,}9710 = H$ exactement.

**F3.10 — Ensemble typique.**
$$A_\epsilon^{(n)} = \Big\{x^n \in \mathcal{X}^n :\ 2^{-n(H+\epsilon)} \le p(x^n) \le 2^{-n(H-\epsilon)}\Big\}$$
*En mots :* les suites dont la probabilité est « à la bonne échelle », ni trop rares ni trop communes. *Conditions :* $\epsilon>0$ fixé, source i.i.d. *Statut :* PROUVÉ (définition). *Exemple :* $p=0{,}6$, $n=100$, $\epsilon=0{,}1$ : l'intervalle de surprise par symbole est $[0{,}8710\ ;\ 1{,}0710]$. Le tirage à $60$ uns ($0{,}9710$) est typique ; celui à $90$ uns vaut $0{,}9\times0{,}7370 + 0{,}1\times1{,}3219 = 0{,}7955 < 0{,}8710$ : atypique, bien que « plus probable » — l'ensemble typique exclut aussi les suites *trop* probables.

**F3.11 — Vitesse de typicité (Chebyshev).**
$$\mathbb{P}\big(X^n \notin A_\epsilon^{(n)}\big) \;\le\; \frac{\sigma^2}{n\epsilon^2}, \qquad \sigma^2 = \operatorname{Var}\big(-\log_2 p(X)\big)$$
*En mots :* la probabilité d'atypicité décroît au moins comme $1/n$. *Conditions :* alphabet fini, $\sigma^2<\infty$. *Statut :* PROUVÉ (inégalité de Chebyshev appliquée à la moyenne de $n$ termes i.i.d.). *Exemple :* Bernoulli $p=0{,}6$ : $\sigma^2 = p(1-p)\big(\log_2\frac{1-p}{p}\big)^2 = 0{,}24\times(0{,}5850)^2 = 0{,}0821$. Pour $n=100$, $\epsilon=0{,}1$ : borne $= 0{,}0821/(100\times 0{,}01) = 0{,}0821$, donc au moins $91{,}8\,\%$ de masse typique. Pour viser $1\,\%$ d'atypicité avec $\epsilon=0{,}1$, il faut $n \ge 0{,}0821/(0{,}01\times 0{,}01) = 822$.

**F3.12 — Cardinalité typique, majoration.**
$$\big|A_\epsilon^{(n)}\big| \;\le\; 2^{\,n(H(X)+\epsilon)}$$
*En mots :* l'ensemble typique est petit, exponentiellement plus petit que $\mathcal{X}^n$ dès que $H<\log_2|\mathcal{X}|$. *Conditions :* tout $n$, tout $\epsilon>0$. *Statut :* PROUVÉ. *Preuve :* $1 \ge \sum_{x^n\in A} p(x^n) \ge |A|\,2^{-n(H+\epsilon)}$. $\square$ *Exemple :* $p=0{,}6$, $n=100$, $\epsilon=0{,}01$ : $|A| \le 2^{98{,}095} \approx 3{,}38\times 10^{29}$, à comparer à $2^{100} \approx 1{,}27\times 10^{30}$ : au plus $26{,}7\,\%$ des suites. Avec $\epsilon=0{,}1$, la majoration $2^{107{,}1}$ dépasse $2^{100}$ : elle est vide. Je le signale plutôt que de le taire — les bornes asymptotiques sont muettes à petit $n$.

**F3.13 — Cardinalité typique, minoration.**
$$\big|A_\epsilon^{(n)}\big| \;\ge\; (1-\delta_n)\,2^{\,n(H(X)-\epsilon)}, \qquad \delta_n = \frac{\sigma^2}{n\epsilon^2}$$
*En mots :* l'ensemble typique n'est pas trop petit non plus : il contient presque toute la masse, donc presque $2^{nH}$ suites. *Conditions :* $n$ assez grand pour que $\delta_n<1$. *Statut :* PROUVÉ. *Preuve :* $1-\delta_n \le \sum_{x^n\in A} p(x^n) \le |A|\,2^{-n(H-\epsilon)}$. $\square$ *Exemple :* $p=0{,}6$, $n=100$, $\epsilon=0{,}1$, $\delta_n=0{,}0821$ : $|A| \ge 0{,}9179\times 2^{87{,}095} \approx 0{,}9179\times 1{,}65\times 10^{26} \approx 1{,}52\times 10^{26}$.

L'image à retenir : sur les $2^{100}$ suites binaires possibles, environ $2^{97}$ suffisent à porter presque toute la probabilité. Trois bits par bloc de cent — voilà le gain que la typicité rend visible.

### 3.5 Théorème du codage de source de Shannon

**Énoncé.** Soit une source i.i.d. de loi $p$ sur un alphabet fini, d'entropie $H$. Un code-bloc de taux $R$ associe à chaque suite de $n$ symboles un mot de $k = \lceil nR\rceil$ bits, avec décodeur. (i) Si $R>H$, il existe une suite de codes dont la probabilité d'erreur tend vers $0$. (ii) Si $R<H$, toute suite de codes a une probabilité d'erreur tendant vers $1$. Statut : PROUVÉ (Shannon 1948) ; la partie directe est démontrée ici en entier à partir de l'AEP, la réciproque également.

**F3.14 — Partie directe : taux réalisable.**
$$k_n = \big\lceil n(H+\epsilon)\big\rceil + 1 \quad\Longrightarrow\quad R_n = \frac{k_n}{n} \xrightarrow[n\to\infty]{} H+\epsilon, \qquad \mathbb{P}(\text{erreur}) \le \delta_n \to 0$$
*En mots :* indexer les suites typiques, plus un bit de drapeau, suffit. *Conditions :* source i.i.d., $\epsilon>0$, dictionnaire partagé entre encodeur et décodeur. *Statut :* PROUVÉ. *Preuve :* par F3.12, $|A_\epsilon^{(n)}| \le 2^{n(H+\epsilon)}$, donc $\lceil n(H+\epsilon)\rceil$ bits indexent toutes les suites typiques. L'encodeur émet le drapeau $1$ puis l'indice si $x^n\in A$, le drapeau $0$ sinon ; le décodeur échoue seulement dans ce second cas, de probabilité $\le \delta_n$ (F3.11). $\square$ *Exemple :* $p=0{,}6$, $n=10^4$, $\epsilon=0{,}01$ : $k = \lceil 9809{,}51\rceil + 1 = 9811$ bits, soit $R = 0{,}9811$ bit/symbole au lieu de $1$ : gain de $1{,}9\,\%$, avec une borne d'erreur de $8{,}2\,\%$ par Chebyshev. Cette borne est grossière ; des bornes de type exponentiel donnent une décroissance bien plus rapide (CONNU, non démontré ici). À $n=100$, la même construction exige $108$ bits : *aucun* gain garanti. Le théorème est asymptotique, et je refuse de le présenter autrement.

**F3.15 — Réciproque : taux impossible.**
$$\mathbb{P}(\text{succès}) \;\le\; \delta_n + 2^{-n(H-\epsilon-R)} \qquad \text{pour tout } 0<\epsilon<H-R$$
*En mots :* sous l'entropie, aucun code-bloc ne peut réussir souvent. *Conditions :* source i.i.d., $R<H$, tout ensemble de décodage $B_n$ de taille $\le 2^{nR}$. *Statut :* PROUVÉ. *Preuve :* $\mathbb{P}(B_n) \le \mathbb{P}(A^{c}) + \sum_{x^n\in B_n\cap A} p(x^n) \le \delta_n + 2^{nR}\,2^{-n(H-\epsilon)}$, qui tend vers $0$ avec $\delta_n$. $\square$ *Exemple :* $H = 0{,}9710$, $R=0{,}9$, $\epsilon=0{,}05$, $n=1000$ : $\delta_n = 0{,}0821/(1000\times 0{,}0025) = 0{,}0328$ et $2^{-1000\times 0{,}0210} \approx 4{,}9\times 10^{-7}$ : succès $\le 3{,}3\,\%$.

Au taux exactement $R=H$, la probabilité de succès tend vers $1/2$ pour une source non dégénérée, aux effets de discrétisation près (CONNU, via le théorème central limite). La frontière est donc franche : *approchable, jamais franchissable*.

Version sans erreur, en longueur variable : par F3.8, $\inf_C \bar L_n/n = H(X)$, et $\bar L \ge H$ pour tout code, tout $n$ (F3.3–F3.5). Les deux formulations disent la même chose dans deux registres de ressources : taux fixe contre longueur moyenne.

### 3.6 Traduction et compression : ce qu'une traduction peut gagner ou perdre

**F3.16 — Coût à deux parties : le dictionnaire compte.**
$$R_{\text{total}} \;=\; \bar L \;+\; \frac{|D|}{n}$$
*En mots :* une traduction « source → bits » transporte aussi son modèle ; le taux réel inclut la description du dictionnaire, amortie sur $n$ symboles. *Conditions :* décodeur ignorant le code à l'avance, dictionnaire de $|D|$ bits transmis une fois. *Statut :* PROUVÉ (identité de comptabilité). *Exemple :* dictionnaire de $40$ bits (convention d'illustration), $\bar L = 2{,}2$, code fixe concurrent à $3$ bits. Pour $n=1000$ : $2{,}2 + 0{,}04 = 2{,}24 < 3$, gain net. Pour $n=10$ : $2{,}2+4 = 6{,}2 > 3$, la compression est *contre-productive*. Seuil : $2{,}2 + 40/n < 3 \iff n > 50$. Une traduction n'est pas bonne dans l'absolu ; elle est bonne à budget fixé.

**F3.17 — Incompressibilité par comptage.**
$$\#\{x\in\{0,1\}^n : |C(x)| < n-c\} \;\le\; 2^{\,n-c}-1 \quad\Longrightarrow\quad \mathbb{P}_{\text{uniforme}}\big(|C(X)|<n-c\big) < 2^{-c}$$
*En mots :* aucune traduction injective ne comprime la majorité des objets ; les compressibles sont exponentiellement rares. *Conditions :* $C$ injective, source uniforme sur $\{0,1\}^n$, $c\ge 1$. *Statut :* PROUVÉ. *Preuve :* il y a $\sum_{j=0}^{n-c-1}2^{j} = 2^{n-c}-1$ mots de longueur $<n-c$, et l'injectivité interdit les collisions. $\square$ *Exemple :* $c=10$ : moins de $1/1024 \approx 0{,}098\,\%$ des suites gagnent ne serait-ce que $10$ bits. Ce lemme est la matrice du chapitre 5.

**F3.18 — Pont vers Kolmogorov.**
$$nH(X) \;\le\; \mathbb{E}\big[K(X^n)\big] \;\le\; nH(X) + K(p) + K(n) + O(1)$$
*En mots :* la complexité de Kolmogorov moyenne d'un bloc i.i.d. vaut $nH$ à un surcoût près indépendant de $n$ : l'entropie est la part *incompressible*, le modèle est la part *fixe*. *Conditions :* loi $p$ calculable, complexité préfixe, machine universelle fixée. *Statut :* CONNU (Li et Vitányi 1993). *Idée :* la minoration vient de l'inégalité de Kraft pour $K$ combinée à F3.5 ; la majoration vient d'un programme à deux parties — décrire $p$ et $n$, puis coder le bloc. *Exemple :* $p=0{,}6$, $n=10^4$ : $nH = 9709{,}5$ bits ; le surcoût est une constante non calculable (chapitre 7), et la part par symbole tend vers $0{,}9710$.

**F3.19 — Descendre sous $H$ : il faut perdre.**
$$R(D) \;=\; \min_{\,p(\hat x\mid x)\ :\ \mathbb{E}[d(X,\hat X)]\le D} I(X;\hat X)$$
*En mots :* sous l'entropie, la traduction devient non injective ; le taux minimal est gouverné par l'information mutuelle survivante, au prix d'une distorsion $D$. *Conditions :* source i.i.d., distorsion additive, $D\ge 0$. *Statut :* CONNU (Shannon 1948 ; Cover et Thomas 1991). *Exemple :* Bernoulli $0{,}5$, distorsion de Hamming, $D=0{,}1$ : $R = 1 - H_b(0{,}1) = 1 - 0{,}4690 = 0{,}5310$ bit/symbole. On passe sous $H=1$, mais $10\,\%$ des bits sont faux : la place a été achetée avec de l'information, pas avec de l'ingéniosité.

C'est la loi générale que je retiens pour le registre des traductions : **une traduction sans perte ne descend jamais sous le plancher informationnel ; descendre plus bas exige une dissipation**, dont le chapitre 11 évaluera le prix physique à partir de Landauer 1961.

**3.1 — Construire le code de Huffman** pour $(0{,}4\ ;\ 0{,}2\ ;\ 0{,}2\ ;\ 0{,}1\ ;\ 0{,}1)$ et calculer $L$. *Indication :* fusionner $0{,}1+0{,}1$, puis deux $0{,}2$, puis les deux plus petits restants. *Correction :* longueurs $(2,2,2,3,3)$, $L = 2{,}2$ bits/symbole, $H = 2{,}1219$, excédent $0{,}0781$.

**3.2 — Vérifier Kraft et sa saturation.** *Correction :* $3\times 2^{-2} + 2\times 2^{-3} = 0{,}75+0{,}25 = 1$. La saturation est structurelle : un arbre de Huffman complet n'a aucun nœud inutile, donc $K=1$ ; par F3.5, tout l'excédent est alors de la divergence $D(p\|q)$, jamais du gaspillage.

**3.3 — Taille de l'ensemble typique** pour $n=100$, $p=0{,}6$, via $|A_\epsilon^{(n)}| \approx 2^{nH(X)}$. *Correction :* $H = 0{,}6\times 0{,}7370 + 0{,}4\times 1{,}3219 = 0{,}9710$ ; $nH = 97{,}095$ ; $2^{97{,}095} \approx 1{,}69\times 10^{29}$, soit $13{,}4\,\%$ des $2^{100} \approx 1{,}27\times 10^{30}$ suites. Comparer aux bornes rigoureuses F3.12–F3.13 et commenter leur lâcheté à $n=100$.

**3.4 — Source uniforme sur $n$ symboles.** Montrer que $H = \log_2 n$ et que tout code uniquement décodable vérifie $L \ge \log_2 n$. En déduire que pour $n=2^k$ le code fixe à $k$ bits est optimal (statut PROUVÉ, via F3.5 et le cas d'égalité). *Nuance à établir :* pour $n$ non puissance de $2$, l'énoncé « le code fixe est optimal » est RÉFUTÉ : avec $n=3$, Huffman donne les longueurs $(1,2,2)$ et $L = 5/3 \approx 1{,}667 < 2 = \lceil\log_2 3\rceil$, tout en restant $\ge \log_2 3 = 1{,}585$. Le code fixe n'est optimal que parmi les codes à longueur constante.

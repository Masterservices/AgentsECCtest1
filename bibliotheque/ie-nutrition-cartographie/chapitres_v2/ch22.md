## Chapitre 22 — Bibliothèque de modèles : fiches prêtes à photocopier

Une carte ne se dessine pas deux fois de la même manière, mais elle se relit souvent selon les mêmes gestes. C'est précisément ce que cherche cette bibliothèque : transformer les moments de captation — observer, décrire une zone, semer une habitude, tracer un chemin, réviser, échanger, faire le point — en opérations simples, reproductibles, presque mécaniques. L'objectif n'est pas d'imposer une méthode rigide, mais de vous éviter de repartir de zéro chaque fois que l'envie ou la nécessité d'écrire revient.

Le lecteur pressé pourra photocopier les pages qui suivent, les glisser dans une chemise et commencer demain matin. Le lecteur curieux y trouvera davantage : une manière de penser par fiches, c'est-à-dire par unités minimes, manipulables, comparables dans le temps. Une fiche est un fragment de terrain. Empilées, elles deviennent un atlas.

Quelques principes avant d'entrer dans la bibliothèque.

**Une fiche, une question.** Si une fiche porte cinq questions à la fois, elle ne répondra jamais. Chaque modèle ici répond à une seule intention : savoir ce qui se passe, comprendre un lieu, installer une graine, choisir un chemin, constater l'évolution, dialoguer, dresser un état des lieux.

**Remplir court.** Une fiche d'observation remplie en dix minutes est plus utile qu'un journal intime de trois pages abandonné au troisième jour. La contrainte de brièveté n'appauvrit pas le relevé : elle le rend tenable, donc durable.

**Garder les brouillons.** Ne jetez pas une fiche incomplète, ratée ou oubliée. Une case vide est une information : elle dit où votre attention a décroché. Relues en série, les imperfections dessinent une seconde carte, celle de votre disponibilité réelle.

**Photocopier, c'est déjà s'engager.** Prendre cinq minutes pour imprimer ou recopier trois modèles crée un support physique. L'écriture sur papier, même brouillonne, ralentit la pensée juste assez pour qu'elle se précise.

Voici donc sept modèles. Utilisez-les tels quels, pliez-les, barrez-y des lignes, agrandissez-les, combinez-les. Ils vous appartiennent dès la première annotation.

### Fiche d'observation 7 jours

#### À quoi elle sert

Le protocole d'observation du chapitre 3 repose sur une idée simple : regarder avant de décider. Cette fiche matérialise la semaine de repérage. Elle ne demande ni jugement, ni objectif, ni résolution. Elle demande des faits : que s'est-il passé, quand, où, avec quelles circonstances. Le jugement viendra plus tard, quand les sept colonnes seront remplies et que la répétition apparaîtra d'elle-même.

La fiche est volontairement réduite à une ligne par jour. Une seule ligne force la sélection : parmi les dizaines d'événements alimentaires d'une journée, lequel mérite d'être noté ? Ce choix prépare déjà la lecture de la carte.

#### La fiche

**Titre de la semaine :** ____________________ **Du** ______ **au** ______

| Jour | Moment et lieu | Ce qui s'est passé (factuel) | Ce qui m'a aidé / gêné | Niveau d'attention (1 à 5) |
|---|---|---|---|---|
| Lundi | | | | |
| Mardi | | | | |
| Mercredi | | | | |
| Jeudi | | | | |
| Vendredi | | | | |
| Samedi | | | | |
| Dimanche | | | | |

**Ce que je remarque en lisant les sept lignes :**

____________________________________________________________

**Une question que cette semaine soulève :**

____________________________________________________________

#### Mode d'emploi

- Remplissez la ligne du soir même, en deux minutes maximum, ou le lendemain matin au réveil si la veille s'est noyée. Ne remettez jamais au-delà de quarante-huit heures : les détails s'érodent vite.
- La colonne « factuel » refuse les adjectifs. « J'ai grignoté trois biscuits devant l'écran vers 16 h » se note ; « j'ai encore trop mangé » non.
- La colonne « aide / gêne » recueille les conditions : lumière, fatigue, présence d'autrui, heure, contenance du frigo. Ce sont les premiers matériaux des futures zones à risque et des futures oasis.
- Le niveau d'attention sert de signal métabolique : une valeur basse (1-2) indique souvent un pilote automatique. Inutile de l'analyser sur le moment ; lisez la colonne à sept.

#### Variante express

Pour les semaines chargées, remplacez le tableau par sept cases à cocher posées en haut d'une page : **« ai-je mangé au moins une fois assis, sans écran ? »** Une croix par jour, rien de plus. Même cette version minimaliste produit, au bout d'un mois, une cartographie de votre rythme.

### Fiche d'une zone (nœud, limites, risques, oasis)

#### À quoi elle sert

Tout territoire se lit par ses lieux. La fiche de zone prend un endroit précis — la cuisine, le bureau de la pause déjeuner, le placard de l'entrée, le distributeur du couloir, la table de la belle-mère — et l'examine selon quatre angles : son **nœud** (ce qui s'y croise), ses **limites** (ce qui le sépare des autres lieux), ses **risques** (ce qui y facilite les débordements) et ses **oasis** (ce qui y soutient le bon). Quatre angles, une page, un lieu à la fois.

On remplit une fiche par zone. Au bout de six ou sept fiches, vous tenez une première carte de votre alimentation quotidienne — bien avant d'avoir dessiné quoi que ce soit.

#### La fiche

**Nom de la zone :** ______________________________

**Type :** ☐ intérieur ☐ extérieur ☐ professionnel ☐ domestique ☐ mobile

**Période de remplissage :** du ______ au ______

**1. Le nœud — ce qui s'y croise**

- Qui y passe (personnes, rôles) :
- À quelles heures il est le plus vivant :
- Quels gestes s'y enchaînent inévitablement :
- Qu'est-ce qui, ici, déclenche systématiquement une décision alimentaire :

**2. Les limites — ce qui le délimite**

- Ce qui sépare cette zone de la suivante (porte, couloir, trajet, écran) :
- Le seuil qu'il faut franchir pour y entrer / en sortir :
- Ce qui rend la frontière poreuse (on y entre « pour une minute ») :
- Une zone voisine qui déborde sur celle-ci :

**3. Les risques — ce qui facilite le dérapage**

- Objets visibles en permanence :
- Situations récurrentes (fatigue, retard, solitude, réunion) :
- Promesses de facilité (plats prêts, snacks, commandes) :
- Le risque numéro un, en une phrase :

**4. Les oasis — ce qui soutient**

- Ce qui est déjà en place et fonctionne :
- Un détail agréable à préserver :
- Une ressource proche (eau, assiette, pause, compagnon) :
- Une idée d'aménagement minime :

**Décision de terrain (une seule ligne) :**

____________________________________________________________

#### Mode d'emploi

- Remplissez d'abord les colonnes **nœud** et **limites** : elles sont descriptives et faciles. Réservez les **risques** à un second passage, quand le lieu est déjà posé sur la page.
- La « décision de terrain » n'est pas un projet. C'est un ajustement de quelques centimètres : déplacer un bol, poser une carafe, fermer un tiroir, changer d'heure, s'installer à une autre table. Une fiche qui se termine par « refaire ma vie » est mal remplie ; une fiche qui se termine par « décaler de trente minutes » est bien remplie.
- Recopiez la fiche après trois semaines, sans regarder l'ancienne. Les écarts révèlent ce qui a bougé dans le terrain — ou dans votre regard.

### Fiche graine (ancre, sol, signal, repli)

#### À quoi elle sert

Une habitude nouvelle est une graine : elle a besoin d'un endroit précis pour tomber, d'un sol qui la nourrisse, d'un moment qui la déclenche et d'un mode de survie quand la saison se gâte. La fiche graine fixe ces quatre paramètres avant toute tentative. Elle remplace les résolutions vagues (« manger mieux », « cuisiner plus ») par un dispositif complet, écrit, vérifiable.

L'essentiel de cette fiche tient en quatre champs. Le dernier — le **repli** — est le plus souvent oublié, et le plus utile : c'est lui qui empêche une semaine difficile de devenir un abandon.

#### La fiche

**Nom que je donne à cette graine :** __________________________

**Formulation complète :** « Je ______________ (action) à ______________ (moment), à ______________ (lieu). »

**1. L'ancre — à quoi je l'accroche**

- L'habitude existante à laquelle je me branche :
- Le moment précis de la journée :
- Le déclencheur physique (objet, notification, porte, machine à café) :

**2. Le sol — ce qui la nourrit**

- Matériel requis (et où il est rangé) :
- Condition de facilité (tout est prêt la veille au soir ?) :
- Élément de plaisir ou de confort associé :
- Personne ou chose qui soutient cette graine :

**3. Le signal — comment je sais qu'elle a germé**

- Indicateur visible, en une phrase :
- Fréquence de vérification : ☐ quotidien ☐ 3 fois/semaine ☐ hebdomadaire
- Premier jalon à 7 jours :
- Premier jalon à 30 jours :

**4. Le repli — que faire quand ça lâche**

- Version réduite (le « mini-grain ») en cas de jour chargé :
- Ce que je ne compte pas faire (interdits à moi-même, max. 3) :
- Ce que je me dirai si j'abandonne trois jours d'affilée :
- Date de reprise automatique : le ______

**Dernière case : pourquoi cette graine compte pour moi (deux lignes) :**

____________________________________________________________
____________________________________________________________

#### Mode d'emploi

- L'**ancre** doit être un moment déjà existant. Créer un nouveau créneau entier — « je cuisinerai le mardi soir » — fonctionne moins bien que de s'accrocher à ce qui a lieu : « après le dernier rendez-vous, avant de rallumer l'écran ».
- Le **sol** est matériel avant d'être psychologique. Une graine qui exige une recherche d'ingrédient à 19 h 30 est mal planifiée, quel que soit votre courage.
- Le **signal** doit être observable par un tiers. « Je me sens mieux » ne se vérifie pas ; « l'assiette du midi contient deux éléments crus » se vérifie.
- Le **repli** transforme l'échec en simple variante. Trois jours de version réduite ne cassent pas une habitude : ils la maintiennent en hiver.

### Fiche itinéraire (scénario, chemin, alternatives)

#### À quoi elle sert

Un itinéraire, dans cette méthode, n'est pas un plan de repas : c'est une suite de décisions prévues pour un moment difficile. Le repas de Noël chez l'oncle, la réunion qui déborde sur le déjeuner, la soirée d'anniversaire, le trajet du vendredi soir — autant de terrains où la volonté brute ne suffit pas. La fiche itinéraire prépare le chemin à l'avance, comme on repère une sortie avant d'entrer dans un bâtiment.

Trois niveaux y figurent : le **scénario** (ce qui va arriver), le **chemin** (ma voie principale) et les **alternatives** (ce que je fais si le chemin est bloqué). L'absence d'alternative est la première cause d'abandon d'un itinéraire.

#### La fiche

**Nom de l'itinéraire :** ______________________________

**Date ou fréquence :** ______________________________

**1. Le scénario — ce qui va se passer**

- Lieu, horaires, durée :
- Personnes présentes :
- Séquence prévisible (arrivée, apéritif, repas, café, départ) :
- Le moment critique (le pic de difficulté) :
- Ce que j'apporte déjà avec moi (état de forme, repas pris avant) :

**2. Le chemin — ma voie principale**

- Étape 1 (avant de partir) :
- Étape 2 (à l'arrivée) :
- Étape 3 (au moment critique) :
- Étape 4 (à la sortie) :
- Mot ou geste qui me recentre (une phrase, un rituel) :

**3. Les alternatives — si le chemin est bloqué**

- Alternative A (si je n'ai pas le choix sur le menu) :
- Alternative B (si je suis très affamé·e en arrivant) :
- Alternative C (si la pression sociale pousse) :
- Alternative D (si je cède plus que prévu — plan de reprise) :

**4. Après — le débrief en trois lignes**

- Ce qui s'est passé réellement :
- Ce qui fonctionnera la prochaine fois :
- Ce que je change dans cette fiche :

#### Mode d'emploi

- Remplissez la fiche **deux jours avant**, jamais la veille au soir : le cerveau nocturne a tendance à promettre des itinéraires héroïques.
- L'étape 3 (moment critique) doit tenir en une phrase actionnable. « Je me calme » est vague ; « je bois un verre d'eau et je vais me tenir debout cinq minutes près de la fenêtre » est un itinéraire.
- L'alternative D est la plus rassurante : prévoir le débordement retire à l'événement son pouvoir de catastrophe. Un itinéraire qui accepte d'être partiellement raté est un itinéraire qui se termine.
- Conservez les fiches d'itinéraire des occasions récurrentes (fêtes annuelles, tour de table mensuel, missions professionnelles). Au deuxième et troisième exercice, vous n'écrirez plus que la colonne « après ».

### Fiche révision saisonnière

#### À quoi elle sert

Les habitudes ont des saisons. Ce qui marchait en novembre s'effrite en février ; ce qui était pénible en juillet devient naturel en octobre. La fiche de révision saisonnière propose un relevé standardisé, à produire quatre fois par an, pour comparer non pas deux opinions mais deux mesures. Elle objective la dérive — dans les deux sens.

Le modèle est volontairement symétrique : mêmes questions, même ordre, sauf une fois par saison. C'est cette symétrie qui rend la comparaison possible.

#### La fiche

**Saison :** ☐ Printemps ☐ Été ☐ Automne ☐ Hiver   **Date du relevé :** ______

**1. Le terrain en surface (état des lieux)**

- Nombre approximatif de zones cartographiées : ______
- Graines en cours : ______   dont version réduite actuellement : ______
- Dernier itinéraire emprunté : ________________________
- Dernière carte dessinée (date) : ________________________

**2. Ce qui pousse**

- L'habitude la plus solide en ce moment, et pourquoi :
- Un lieu qui s'est transformé sans effort apparent :
- Une facilité que j'ai installée et qui fonctionne :

**3. Ce qui stagne ou meurt**

- La graine qui n'a pas pris :
- Le risque qui revient toujours :
- Le signe d'usure que j'avais sous-estimé :

**4. Le relief de la saison (climat, rythme, événements)**

- Conditions météo et lumière :
- Rythme de travail / sommeil :
- Événements à venir (fêtes, congés, exams, déplacements) :

**5. Révisions à opérer (max. 3)**

1. ____________________________________________________________
2. ____________________________________________________________
3. ____________________________________________________________

**6. Une question à porter jusqu'à la prochaine saison**

____________________________________________________________

#### Mode d'emploi

- Remplissez la fiche à la **même période** chaque fois — idéalement dans les quinze jours suivant le changement de saison, quand le contraste est perceptible.
- Limitez les révisions à **trois**. Une fiche qui en propose dix produit un sentiment de retard ; une fiche qui en propose trois produit un sentiment de marche.
- Conservez les quatre relevés de l'année côte à côte. La lecture horizontale — printemps, été, automne, hiver sur la même ligne — est souvent plus parlante que n'importe quel journal.

### Grille d'entretien avec un proche

#### À quoi elle sert

Cartographier à deux ne signifie pas convaincre l'autre. Cette grille sert à conduire une conversation courte, factuelle et non militante — avec un conjoint, un colocataire, un ami, un parent adulte, un collègue de bureau. Elle structure l'échange en cinq temps pour éviter les deux écueils classiques : le monologue sur ses propres objectifs, et le reproche déguisé sur les habitudes de l'autre.

La grille tient sur une feuille. Prévoyez vingt minutes, un endroit calme, et l'accord explicite de votre interlocuteur. Sans cet accord, ne sortez pas la fiche : parlez d'abord, notez après.

#### La fiche

**Avec :** ____________________ **Date :** ______ **Durée :** ______

**Règles posées au départ (à lire à voix haute)**

- ☐ On ne donne pas de conseil non demandé.
- ☐ On ne commente pas l'assiette de l'autre.
- ☐ Chacun peut passer une question.

**1. Le terrain commun (5 min)**

- Quels sont nos lieux alimentaires partagés (cuisine, table, courses, soirées) ?
- Qu'est-ce qui fonctionne déjà sans discussion ?

**2. Le regard de chacun (5 min)**

- Qu'est-ce qui est facile pour vous en ce moment ?
- Qu'est-ce qui vous coûte, ici ?

**3. Une zone à aménager ensemble (5 min)**

- Quel lieu ou quel moment voudrions-nous ajuster ?
- Quel est le plus petit changement visible par tous les deux ?

**4. La graine partagée (3 min)**

- Une seule chose que l'on essaie ensemble pendant deux semaines :
- Chacun écrit sa version de la formulation « je ______ à ______, à ______ » :

**5. Le point de reprise (2 min)**

- Rendez-vous de bilan : le ______   **Format :** ☐ café ☐ repas ☐ simple discussion

**Note libre (après l'entretien) :**

____________________________________________________________

#### Mode d'emploi

- Commencez toujours par la section 1. Nommer ce qui fonctionne crée un socle ; commencer par les problèmes installe un tribunal.
- La graine partagée doit être **vraiment minime** : un seul élément, deux semaines, n'importe lequel des deux peut abandonner sans que l'autre en souffre. L'objectif est l'entraînement au dialogue, pas la performance alimentaire.
- Si la conversation dérape, interrompez le remplissage et rangez la fiche. Une grille d'entretien est un instrument, pas un juge de paix. Reprenez-la au rendez-vous suivant.

### Bilan mensuel en une page

#### À quoi elle sert

Le dernier modèle est aussi le plus court. Une page, une fois par mois, pour prendre la mesure sans se perdre. Le bilan ne juge pas, ne réforme pas, ne crée pas de nouvelle graine : il constate. Toute décision nouvelle se reporte à la fiche de révision saisonnière ou à la fiche graine — c'est la discipline de cette bibliothèque : **chaque question a sa fiche.**

Le bilan tient en quatre blocs, un quart de page chacun, plus une ligne de clôture.

#### La fiche

**Mois :** ____________________ **Date du bilan :** ______

**BLOC 1 — Le relevé (les chiffres, sans commentaire)**

| Indicateur | Valeur |
|---|---|
| Jours d'observation remplis (sur 7 ou 30) | |
| Graines en cours / germées / arrêtées | |
| Zones revisitées ce mois-ci | |
| Itinéraires empruntés | |
| Fiches produites (total) | |

**BLOC 2 — Trois faits marquants**

1. ____________________________________________________________
2. ____________________________________________________________
3. ____________________________________________________________

**BLOC 3 — Un obstacle, une ressource**

- L'obstacle le plus récurrent :
- La ressource la plus fiable :

**BLOC 4 — Ce que je ne change pas**

(Un mois réussi se reconnaît aussi à ce qu'on décide de laisser intact.)

____________________________________________________________

**Ligne de clôture — la question du mois prochain :**

____________________________________________________________

#### Mode d'emploi

- Fixez une date de bilan dans le calendrier, à la fin du mois, un dimanche si possible. Vingt minutes suffisent si les fiches de la semaine existent ; elles deviennent alors une simple collecte.
- **BLOC 4** est le cœur du modèle. Beaucoup d'approches cumulent les ajustements jusqu'à l'épuisement. Ici, on consigne explicitement ce qui reste en place : un meuble, une heure, une habitude, une absence d'interdit. Sans ce bloc, un bilan mensuel ressemble à une liste de reproches.
- Si le mois a été chaotique, remplissez quand même. Une page de bilan presque vide est un relevé honnête ; une page de bilan sautée crée un vide qui, lui, se remplit de culpabilité.

### Exercices

#### Exercice 1 — Composer son classeur de terrain à partir de trois modèles au choix

Prenez une chemise à sangles, un classeur à pochettes ou un simple trombone. Versez-y **exactement trois modèles**, choisis selon votre situation actuelle, et non selon ce qui vous semble le plus ambitieux.

Quelques combinaisons types, à titre d'inspiration :

- **Débutant complet :** fiche d'observation 7 jours + fiche d'une zone + bilan mensuel. Vous observez, vous décrivez un lieu, vous comptez. Rien d'autre pendant trente jours.
- **Semer une habitude :** fiche graine + fiche d'observation + bilan mensuel. La graine donne l'action, l'observation donne le retour de terrain, le bilan donne la perspective.
- **Préparer un événement :** fiche itinéraire + fiche d'une zone + grille d'entretien. Le repas de famille, le voyage, la rentrée en colocation.
- **Réorienter après une période creuse :** fiche de révision saisonnière + fiche d'observation + fiche d'une zone.

Ajoutez en première page une **page de garde manuscrite** contenant trois lignes seulement : mon nom, la date de démarrage, et la phrase « je remplis d'abord, je comprends ensuite ». C'est suffisant pour que le classeur devienne un objet avec lequel vous avez une relation.

*Délai :* trente minutes. *Livrable :* un classeur fermé, prêt sur la table.

#### Exercice 2 — Adapter une fiche à sa situation

Aucun des modèles ci-dessus ne vise l'universalité parfaite. Votre situation impose ses contraintes ; la fiche doit s'y plier. Choisissez **une** fiche et **une** situation, puis réécrivez-la intégralement — à la main, sur une page blanche, sans vous référer à la version d'origine autrement que pour en garder la structure.

Suggestions d'adaptations :

- **Étudiant·e :** réduisez la fiche d'observation à cinq lignes (jours de cours seulement) et ajoutez une colonne « lieu » entre « horaire » et « repas ». Remplacez la colonne « oasis » de la fiche de zone par « ressource gratuite » (bibliothèque, cuisine du foyer, marché du jeudi).
- **Parent d'enfants en bas âge :** sur la fiche graine, l'ancre devient un moment de l'enfant (« après le bain », « à la sortie de l'école »). Ajoutez un champ « version à deux mains » : que faire quand une main est occupée. Réduisez le signal à une seule observation par jour.
- **Télétravail :** la fiche d'une zone se centre sur la frontière bureau/cuisine. Créez une nouvelle ligne dans les limites : « ce que je vois depuis mon écran ». L'itinéraire devient « traversée de midi » : le trajet artificiel entre deux pièces qui remplace le trajet réel.
- **Déplacements fréquents :** abandonnez le tableau de sept jours au profit de la variante par coche. Remplacez la fiche de zone par une **fiche de territoire mobile** : avion, train, hôtel, restaurant d'aéroport — lieux éphémères mais répétés. L'itinéraire devient une **carte de secours** : trois options par type de repas (petit-déjeuner, déjeuner, dîner) disponibles partout.

À la fin de l'exercice, écrivez en bas de page : « Cette fiche est passée de ______ à ______ mots, parce que ______ ». Cette ligne rend visible votre raisonnement d'adaptateur.

*Délai :* quarante-cinq minutes. *Livrable :* une fiche personnalisée, signée et datée.

#### Exercice 3 — Test d'une fiche pendant sept jours et retouche du modèle

Une fiche n'existe vraiment qu'après usage. Choisissez le modèle qui vous intrigue le plus — celui que vous n'auriez pas choisi spontanément — et mettez-le à l'épreuve pendant une semaine complète.

**Jours 1 à 7 :** remplissez la fiche chaque jour ou chaque fois qu'elle le demande, sans en modifier la structure. Résistez à l'envie d'améliorer en cours de route : les modifications prématurées faussent le test, car vous ne saurez plus si c'est la fiche qui ne va pas ou votre attention qui flanche.

**Jour 7 (ou jour 8) :** imprimez ou recopiez une fiche vierge, placez-la à côté de la version usée, et remplissez un tableau de retouche :

| Ce qui a manqué (case impossible à remplir) | Ce qui était inutile (case toujours vide) | Ce qui a été mal compris (case remplie à côté) | Hypothèse de correction |
|---|---|---|---|
| | | | |

**Ensuite, uniquement ensuite,** retouchez le modèle. Trois règles de retouche :

1. **Jamais plus de trois modifications** par cycle. Au-delà, vous réinventez un modèle au lieu de l'affiner.
2. **Une case ajoutée doit compenser une case supprimée.** Si la fiche grossit à chaque révision, elle mourra sous son propre poids.
3. **Numérotez les versions** en bas de page : « V1 — février », « V2 — avril ». Une bibliothèque de modèles vivante est une bibliothèque versionnée.

Relancez le test sur sept nouveaux jours avec la version corrigée. À la quatrième itération, vous posséderez un outil qui vous ressemble — et qui, recopié pour un proche, peut lui rendre service tel quel.

*Délai :* sept jours de test, trente minutes de retouche. *Livrable :* une fiche V2 annotée et une note d'une phrase sur ce qu'elle a changé dans votre manière d'observer.

### Notes de fin de chapitre

Une bibliothèque de modèles n'a de valeur que si elle reste ouverte. Les sept fiches présentées ici ne sont pas des formulaires administratifs : ce sont des conversations pré-écrites avec votre terrain. Une case se remplit, une autre reste vide, une troisième vous surprend — et c'est là que la carte commence.

Le classeur, lui, finit toujours par s'épaissir. Au bout d'un an, vous aurez des fiches de saisons contrastées, des graines mortes et des graines robustes, des itinéraires devenus des habitudes, des bilans presque identiques les uns aux autres — signe, souvent, que le terrain s'est stabilisé. Alors surviendra l'envie de tout refaire, de dessiner une carte plus belle, plus complète, plus lisible.

Gardez-en envie, mais gardez aussi les anciennes fiches. C'est en les relu l'une après l'autre que l'on mesure le chemin réel — celui qui ne se voit jamais le jour où on le parcourt, mais seulement lorsqu'on compare deux pages séparées par un printemps.

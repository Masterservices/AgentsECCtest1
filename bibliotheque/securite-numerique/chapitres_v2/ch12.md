## Chapitre 12 : Navigation web sécurisée

Internet est devenu notre fenêtre principale sur le monde. Nous y travaillons, nous y achetons, nous y communiquons, nous y apprenons. Mais cette fenêtre est à double sens : pendant que nous observons le web, le web nous observe en retour. Chaque clic, chaque recherche, chaque page visitée laisse une empreinte que des centaines d'acteurs s'empressent de collecter, d'analyser et souvent de monnayer.

La navigation web sécurisée n'est pas un luxe réservé aux journalistes d'investigation ou aux lanceurs d'alerte. C'est une nécessité pour quiconque souhaite préserver sa vie privée, protéger ses données personnelles et éviter de devenir la cible de cybercriminels ou la proie de manipulateurs publicitaires. Dans ce chapitre, nous allons transformer votre navigateur en forteresse et vous donner les clés pour naviguer sans laisser de traces indésirables.

### HTTPS et certificats SSL/TLS : comprendre le chiffrement web

Lorsque vous tapez une adresse web ou cliquez sur un lien, votre navigateur établit une connexion avec un serveur distant. Sans protection, cette connexion est comme une carte postale : tout ce qui transite entre votre appareil et le serveur peut être lu par n'importe quel intermédiaire sur le réseau. C'est là qu'intervient HTTPS.

HTTPS (HyperText Transfer Protocol Secure) est la version sécurisée du protocole HTTP. La différence fondamentale réside dans le chiffrement : avec HTTPS, toutes les données échangées entre votre navigateur et le site web sont chiffrées grâce aux protocoles SSL (Secure Sockets Layer) ou son successeur TLS (Transport Layer Security).

Concrètement, cela signifie que même si quelqu'un intercepte le trafic entre vous et le serveur, il ne verra qu'une suite de caractères incompréhensibles. Votre mot de passe, vos informations bancaires, vos messages privés restent confidentiels.

**Comment reconnaître une connexion HTTPS ?**

La méthode la plus simple consiste à vérifier la barre d'adresse de votre navigateur. Une connexion sécurisée affiche :
- Un cadenas (généralement vert ou gris) à gauche de l'URL
- L'adresse commence par "https://" plutôt que "http://"

Cliquez sur ce cadenas pour afficher les détails du certificat. Vous y trouverez le nom de l'organisation propriétaire du certificat, l'autorité de certification qui l'a délivré, et la période de validité.

**Les certificats SSL/TLS : une question de confiance**

Un certificat SSL/TLS est un fichier numérique qui atteste de l'identité d'un serveur web et permet d'établir une connexion chiffrée. Ces certificats sont délivrés par des autorités de certification (CA) reconnues, qui vérifient que le demandeur contrôle bien le domaine concerné.

Il existe différents niveaux de validation :
- **Validation de domaine (DV)** : l'autorité vérifie simplement que vous contrôlez le domaine. C'est le niveau le plus basique, souvent gratuit via Let's Encrypt.
- **Validation d'organisation (OV)** : l'autorité vérifie l'existence légale de l'organisation.
- **Validation étendue (EV)** : vérification approfondie de l'identité juridique et physique de l'organisation. Les navigateurs affichent parfois le nom de l'organisation en vert.

**Les limites du HTTPS**

HTTPS protège le contenu de vos communications, mais pas les métadonnées. Un observateur peut toujours voir quels sites vous visitez (via le DNS ou le nom de domaine dans le certificat), même s'il ne peut pas voir ce que vous y faites. De plus, HTTPS ne vous protège pas contre les sites malveillants : un site de phishing peut parfaitement avoir un certificat valide.

C'est pourquoi HTTPS est une condition nécessaire mais non suffisante pour une navigation sécurisée. Il doit être complété par d'autres mesures que nous allons explorer.

### Extensions de navigateur essentielles

Votre navigateur est votre véhicule pour explorer le web. Par défaut, il est configuré pour la commodité et la compatibilité, pas pour la sécurité et la vie privée. Heureusement, les extensions permettent de transformer radicalement son comportement.

**uBlock Origin : le bouclier anti-publicités et anti-trackers**

uBlock Origin n'est pas simplement un bloqueur de publicités. C'est un outil de filtrage puissant qui bloque les publicités, les trackers, les scripts malveillants et les mineurs de cryptomonnaie qui ralentissent votre navigateur.

Contrairement à d'autres bloqueurs, uBlock Origin est open source, gratuit, et ne vend pas vos données. Il consomme très peu de ressources et offre un contrôle granulaire sur ce qui est bloqué. Vous pouvez personnaliser les listes de filtres, créer vos propres règles, et même bloquer des éléments spécifiques sur une page.

Installation : disponible sur Firefox, Chrome, Edge et Safari. Après l'installation, il fonctionne immédiatement avec des listes de filtres prédéfinies. Pour une protection optimale, activez les listes supplémentaires dans les paramètres (listes de protection contre les malwares, listes régionales, etc.).

**HTTPS Everywhere : forcer les connexions sécurisées**

Développé par l'Electronic Frontier Foundation (EFF), HTTPS Everywhere réécrit automatiquement les requêtes HTTP en HTTPS pour les sites qui supportent les deux protocoles. Même si vous tapez "http://example.com" ou cliquez sur un lien non sécurisé, l'extension vous redirige vers la version HTTPS.

Note importante : depuis 2022, la plupart des navigateurs modernes intègrent nativement une fonctionnalité similaire appelée "HTTPS-First Mode" ou "HTTPS-Only Mode". Vérifiez dans les paramètres de sécurité de votre navigateur si cette option est disponible et activez-la. Si c'est le cas, HTTPS Everywhere devient redondant.

**Privacy Badger : l'apprenti anti-tracking**

Autre création de l'EFF, Privacy Badger adopte une approche différente des bloqueurs traditionnels. Au lieu de s'appuyer sur des listes noires prédéfinies, il apprend en observant le comportement des trackers pendant votre navigation.

Si Privacy Badger détecte qu'un domaine tiers vous suit à travers plusieurs sites sans votre consentement, il le bloque automatiquement. Cette approche heuristique permet de détecter de nouveaux trackers qui n'auraient pas encore été ajoutés aux listes statiques.

Privacy Badger respecte également les signaux "Do Not Track" (DNT) et bloque les trackers qui ne les respectent pas. Il est particulièrement efficace contre les techniques de fingerprinting et les cookies tiers.

**Autres extensions recommandées**

- **ClearURLs** : supprime automatiquement les paramètres de suivi dans les URLs (comme les UTM trackers utilisés par Google Analytics).
- **Decentraleyes** : sert localement les bibliothèques JavaScript courantes (jQuery, etc.) pour éviter de les charger depuis des CDN tiers qui peuvent vous tracker.
- **Cookie AutoDelete** : supprime automatiquement les cookies des sites que vous ne visitez plus après un délai configurable.

**Attention à la surcharge d'extensions**

Installer trop d'extensions peut paradoxalement nuire à votre sécurité. Chaque extension a accès à vos données de navigation et peut potentiellement les exfiltrer. De plus, certaines extensions peuvent entrer en conflit ou ralentir votre navigateur.

Règle d'or : n'installez que les extensions dont vous avez vraiment besoin, provenant de sources de confiance, et vérifiez régulièrement les permissions qu'elles demandent. Supprimez celles que vous n'utilisez plus.

### Gestion des cookies et du tracking

Les cookies sont de petits fichiers texte que les sites web stockent sur votre appareil pour mémoriser des informations vous concernant. Initialement conçus pour des fonctions légitimes (maintenir votre session, sauvegarder vos préférences), ils sont devenus l'outil principal du tracking publicitaire.

**Les différents types de cookies**

- **Cookies propriétaires (first-party)** : définis par le site que vous visitez directement. Ils servent généralement à des fonctions essentielles comme l'authentification.
- **Cookies tiers (third-party)** : définis par des domaines autres que celui que vous visitez, souvent des régies publicitaires ou des services d'analyse. Ce sont les principaux vecteurs de tracking cross-site.
- **Cookies de session** : supprimés à la fermeture du navigateur.
- **Cookies persistants** : restent sur votre appareil jusqu'à leur expiration ou suppression manuelle.

**Configurer votre navigateur pour limiter le tracking**

Tous les navigateurs modernes offrent des paramètres de confidentialité permettant de contrôler les cookies :

1. **Bloquer les cookies tiers** : c'est le minimum syndical. La plupart des navigateurs le proposent désormais par défaut ou en option.
2. **Supprimer les cookies à la fermeture** : option radicale mais efficace pour éviter l'accumulation de données.
3. **Mode navigation privée** : les cookies sont supprimés à la fermeture de la fenêtre, mais attention : cela ne vous rend pas anonyme pour autant.
4. **Isolation des cookies** : certains navigateurs comme Firefox proposent l'isolation totale des cookies (Total Cookie Protection), qui empêche les trackers d'utiliser les cookies pour vous suivre d'un site à l'autre.

**Les bannières de consentement : un théâtre absurde**

Depuis le RGPD en Europe, vous êtes bombardé de bannières vous demandant d'accepter les cookies. La plupart sont conçues pour vous fatiguer et vous faire cliquer sur "Tout accepter" par lassitude.

Quelques stratégies pour gérer ce fléau :
- **Refuser systématiquement** : prenez l'habitude de cliquer sur "Refuser" ou "Paramétrer" pour n'accepter que les cookies strictement nécessaires.
- **Extensions anti-bannières** : des outils comme "I don't care about cookies" ou "Consent-O-Matic" refusent automatiquement les cookies non essentiels pour vous.
- **Signaler les violations** : si un site ne propose pas d'option de refus claire ou rend le refus excessivement difficile, vous pouvez le signaler à la CNIL (en France) ou à l'autorité de protection des données de votre pays.

**Au-delà des cookies : les autres techniques de tracking**

Les cookies ne sont qu'une des nombreuses méthodes de tracking. Les annonceurs utilisent également :

- **Fingerprinting** : collecte d'informations sur votre configuration (résolution d'écran, polices installées, plugins, fuseau horaire, etc.) pour créer une empreinte unique de votre appareil.
- **Tracking par canvas** : utilisation de l'API Canvas pour générer une image qui varie selon votre configuration matérielle et logicielle.
- **WebRTC leaks** : l'API WebRTC peut révéler votre adresse IP réelle même si vous utilisez un VPN.
- **Supercookies** : stockage de données dans d'autres emplacements que les cookies traditionnels (LocalStorage, IndexedDB, cache ETag, etc.).

Privacy Badger et uBlock Origin offrent une certaine protection contre ces techniques, mais aucune solution n'est parfaite. C'est pourquoi le choix du navigateur lui-même est crucial.

### Navigateurs orientés vie privée

Le navigateur que vous utilisez quotidiennement a un impact énorme sur votre vie privée en ligne. Les navigateurs grand public comme Chrome, Safari ou Edge sont développés par des entreprises dont le modèle économique repose en partie sur la publicité ciblée. Leurs intérêts ne sont pas toujours alignés avec votre droit à la vie privée.

**Firefox : le champion open source**

Développé par Mozilla, Firefox est un navigateur open source qui place la vie privée au cœur de ses priorités. Mozilla est une organisation à but non lucratif, ce qui signifie qu'elle n'a pas d'actionnaires à satisfaire ni de données à monnayer.

Avantages de Firefox pour la vie privée :
- **Protection renforcée contre le pistage** : bloque par défaut les cookies tiers, les trackers connus, les mineurs de cryptomonnaie et les scripts de fingerprinting.
- **Isolation totale des cookies** : chaque site est isolé dans son propre conteneur, empêchant le tracking cross-site.
- **DNS over HTTPS (DoH)** : chiffre vos requêtes DNS pour empêcher votre fournisseur d'accès de voir quels sites vous visitez.
- **Personnalisation avancée** : via la page `about:config`, vous pouvez durcir Firefox bien au-delà des paramètres standards.
- **Extensions puissantes** : Firefox autorise des extensions plus puissantes que Chrome, notamment uBlock Origin avec toutes ses fonctionnalités.

Configuration recommandée pour Firefox :
- Activez le mode "Protection renforcée contre le pistage" en mode "Strict"
- Dans les paramètres de confidentialité, choisissez "Strict" pour le blocage de contenu
- Activez "Ne jamais se souvenir de l'historique" ou configurez la suppression automatique des cookies à la fermeture
- Désactivez la télémétrie dans les paramètres de confidentialité

**Brave : la commodité avec une conscience**

Brave est un navigateur basé sur Chromium (le même moteur que Chrome) qui bloque nativement les publicités et les trackers. Il offre une expérience familière aux utilisateurs de Chrome tout en améliorant significativement la vie privée.

Points forts de Brave :
- **Blocage intégré** : Shields bloque automatiquement publicités, trackers et scripts malveillants sans configuration.
- **Compatibilité Chrome** : vous pouvez installer les extensions du Chrome Web Store.
- **Tor intégré** : une option permet d'ouvrir des onglets privés via le réseau Tor.
- **Brave Search** : moteur de recherche intégré qui ne vous tracke pas.

Points de vigilance :
- Brave a suscité des controverses concernant ses publicités opt-in (Brave Rewards) et ses partenariats avec des cryptomonnaies.
- L'entreprise derrière Brave est une société à but lucratif, contrairement à Mozilla.

**Tor Browser : l'anonymat maximal**

Tor Browser est conçu pour anonymiser complètement votre navigation en faisant transiter votre trafic à travers au moins trois serveurs (nœuds) volontaires répartis dans le monde. Chaque nœud ne connaît que le nœud précédent et le suivant, rendant extrêmement difficile de retracer l'origine du trafic.

Tor Browser est basé sur Firefox mais avec des modifications profondes :
- Toutes les fenêtres ont la même taille pour éviter le fingerprinting par résolution
- JavaScript est restreint
- Les plugins sont désactivés
- L'historique et les cookies sont supprimés à chaque fermeture
- Toutes les connexions passent par le réseau Tor

Cas d'usage légitimes pour Tor :
- Journalistes protégeant leurs sources
- Militants dans des pays répressifs
- Contournement de la censure
- Recherche sensible nécessitant l'anonymat total

Limitations de Tor :
- Vitesse réduite (le trafic passe par plusieurs serveurs)
- Certains sites bloquent les adresses IP Tor
- Ne protège que le trafic du navigateur, pas les autres applications
- L'utilisation de Tor peut attirer l'attention dans certains contextes

**Quel navigateur choisir ?**

Pour un usage quotidien avec un bon équilibre vie privée/commodité : **Firefox** avec une configuration durcie.

Pour une transition douce depuis Chrome : **Brave**.

Pour des activités nécessitant l'anonymat : **Tor Browser**.

Idéalement, utilisez plusieurs navigateurs selon le contexte : Firefox pour la navigation quotidienne, Tor Browser pour les recherches sensibles.

### Moteurs de recherche respectueux

Votre moteur de recherche en sait énormément sur vous. Chaque requête révèle vos intérêts, vos préoccupations, votre état de santé, vos opinions politiques. Google, le leader du marché, utilise ces données pour construire un profil publicitaire extrêmement détaillé.

Heureusement, des alternatives respectueuses de la vie privée existent.

**DuckDuckGo : la référence grand public**

DuckDuckGo est le moteur de recherche privé le plus connu. Il ne collecte pas d'informations personnelles, ne crée pas de profil utilisateur, et affiche les mêmes résultats à tout le monde pour une même requête (pas de "bulle de filtrage").

Avantages :
- Interface simple et familière
- Résultats de qualité correcte pour la plupart des requêtes
- Fonctionnalités intégrées (réponses instantanées, calculatrice, conversions)
- Application mobile et extension de navigateur disponibles

Limitations :
- Utilise principalement les résultats de Bing (Microsoft)
- Affiche des publicités contextuelles basées sur la requête actuelle (mais pas sur votre historique)
- Entreprise américaine soumise au droit américain

**Startpage : Google sans le tracking**

Startpage propose une approche unique : il vous donne les résultats de Google sans que Google ne sache qui vous êtes. Startpage sert d'intermédiaire : il reçoit votre requête, la transmet anonymement à Google, et vous renvoie les résultats.

Avantages :
- Qualité des résultats de Google
- Pas de tracking ni de profilage
- Entreprise basée aux Pays-Bas (protection RGPD)
- Option "Vue anonyme" pour visiter les sites résultats via un proxy

Limitations :
- Dépendance à l'infrastructure de Google
- Moins de fonctionnalités annexes que DuckDuckGo

**Qwant : l'alternative européenne**

Qwant est un moteur de recherche français qui se positionne comme respectueux de la vie privée. Il ne tracke pas les utilisateurs et ne personnalise pas les résultats.

Avantages :
- Entreprise européenne soumise au RGPD
- Résultats diversifiés (web, actualités, réseaux sociaux, shopping)
- Interface moderne
- Version junior pour les enfants (Qwant Junior)

Limitations :
- Utilise en partie les résultats de Bing
- Résultats parfois moins pertinents que Google pour des requêtes techniques
- A fait face à des critiques concernant ses liens avec Microsoft

**Autres alternatives notables**

- **Searx** : métamoteur open source que vous pouvez héberger vous-même. Il agrège les résultats de plusieurs moteurs sans tracking.
- **Mojeek** : moteur de recherche indépendant avec son propre index (ne dépend pas de Google ou Bing).
- **Brave Search** : moteur de Brave avec son propre index, en croissance constante.

**Conseils pratiques**

1. Définissez un moteur de recherche privé comme moteur par défaut dans votre navigateur.
2. Utilisez des raccourcis pour changer rapidement de moteur selon le type de recherche (!g pour Google via DuckDuckGo, !w pour Wikipedia, etc.).
3. Pour les recherches très sensibles, utilisez Tor Browser avec DuckDuckGo en version .onion.

### Réseaux privés virtuels (VPN) : quand et comment les utiliser

Un VPN (Virtual Private Network) crée un tunnel chiffré entre votre appareil et un serveur distant. Tout votre trafic Internet passe par ce tunnel, masquant votre adresse IP réelle et chiffrant vos données vis-à-vis de votre fournisseur d'accès Internet (FAI) et des éventuels observateurs sur le réseau local.

**Ce qu'un VPN fait réellement**

- **Masque votre adresse IP** : les sites web voient l'adresse IP du serveur VPN, pas la vôtre.
- **Chiffre votre trafic** : votre FAI ne peut pas voir quels sites vous visitez (mais il sait que vous utilisez un VPN).
- **Protège sur les réseaux non fiables** : essentiel dans les cafés, hôtels, aéroports où le Wi-Fi peut être surveillé.
- **Contourne la géo-restriction** : accéder à des contenus limités à certaines régions (attention aux conditions d'utilisation des services).

**Ce qu'un VPN ne fait pas**

- **Ne vous rend pas anonyme** : le fournisseur VPN voit tout votre trafic. Vous devez lui faire confiance.
- **Ne protège pas contre le tracking** : les cookies, le fingerprinting et autres techniques fonctionnent toujours.
- **Ne chiffre que le trafic entre vous et le serveur VPN** : si vous visitez un site en HTTP, le trafic entre le VPN et le site n'est pas chiffré.
- **Ne protège pas contre les malwares ou le phishing**.

**Choisir un fournisseur VPN**

Le marché des VPN est saturé de promesses marketing trompeuses. Voici les critères essentiels pour choisir un fournisseur sérieux :

1. **Politique de non-journalisation (no-logs) vérifiée** : le fournisseur ne doit pas conserver de logs de connexion ni d'activité. Idéalement, cette politique a été auditée par un tiers indépendant.

2. **Juridiction favorable** : évitez les pays avec des lois de surveillance invasive (États-Unis, Royaume-Uni, Australie, etc.). Privilégiez la Suisse, l'Islande, les Pays-Bas, la Roumanie.

3. **Protocoles modernes** : WireGuard ou OpenVPN. Évitez les protocoles propriétaires ou obsolètes (PPTP).

4. **Transparence** : le fournisseur publie-t-il des rapports de transparence ? A-t-il été audité ? Son code est-il open source ?

5. **Performance** : testez la vitesse avant de vous engager. La plupart offrent une garantie de remboursement.

6. **Fonctionnalités de sécurité** : kill switch (coupe la connexion si le VPN tombe), protection contre les fuites DNS, serveurs en RAM uniquement (données effacées au redémarrage).

**Fournisseurs VPN recommandés (à vérifier au moment de votre choix)**

- **Mullvad** : basé en Suède, accepte les paiements anonymes (cash, crypto), pas d'email requis, audités régulièrement.
- **ProtonVPN** : basé en Suisse, développé par l'équipe de ProtonMail, offre gratuite limitée disponible, open source.
- **IVPN** : basé à Gibraltar, audités, accepte les paiements anonymes, transparence exemplaire.

**Quand utiliser un VPN ?**

- **Toujours sur les réseaux Wi-Fi publics** : protection contre les attaques MITM (man-in-the-middle).
- **Pour masquer votre trafic à votre FAI** : si vous ne faites pas confiance à votre fournisseur d'accès.
- **Pour accéder à des contenus géo-restreints** : en respectant les conditions d'utilisation.
- **En voyage dans des pays à surveillance élevée**.

**Quand un VPN n'est pas nécessaire ?**

- Si vous utilisez HTTPS partout et que vous faites confiance à votre FAI.
- Pour l'anonymat total (utilisez Tor à la place).
- Si le fournisseur VPN n'est pas digne de confiance (vous déplacez simplement le problème).

**VPN et Tor : combinaison avancée**

Vous pouvez combiner VPN et Tor pour une protection supplémentaire, mais la configuration est cruciale :

- **Tor over VPN** : vous vous connectez au VPN, puis à Tor. Votre FAI voit que vous utilisez un VPN mais ne sait pas que vous utilisez Tor. Le nœud d'entrée Tor voit l'adresse IP du VPN. Recommandé pour la plupart des cas.

- **VPN over Tor** : vous vous connectez à Tor, puis au VPN. Complexe à configurer, peu d'avantages pratiques, déconseillé sauf cas très spécifiques.

### Tor et réseaux anonymes : principes et cas d'usage

Tor (The Onion Router) est bien plus qu'un navigateur : c'est un réseau décentralisé de serveurs volontaires qui permet d'anonymiser le trafic Internet. Le nom vient du "routage en oignon" : vos données sont enveloppées dans plusieurs couches de chiffrement, comme les couches d'un oignon.

**Fonctionnement de Tor**

Lorsque vous utilisez Tor Browser pour visiter un site :

1. Votre trafic est chiffré en plusieurs couches et envoyé à un **nœud d'entrée** (guard node).
2. Le nœud d'entrée retire la première couche de chiffrement et transmet au **nœud du milieu**.
3. Le nœud du milieu retire la deuxième couche et transmet au **nœud de sortie**.
4. Le nœud de sortie retire la dernière couche et envoie votre requête au site destination.

Chaque nœud ne connaît que le nœud précédent et le suivant. Aucun nœud seul ne peut vous identifier et voir votre trafic complet. Le site destination voit l'adresse IP du nœud de sortie, pas la vôtre.

**Services onion : le web caché**

Tor permet également d'accéder à des "services onion" (anciennement "hidden services"), des sites accessibles uniquement via le réseau Tor avec des adresses se terminant par `.onion`. Ces services offrent :

- Anonymat pour le visiteur ET pour l'hébergeur du site
- Résistance à la censure (difficile de localiser et bloquer le serveur)
- Protection contre la surveillance de masse

Exemples légitimes de services onion :
- Sites de médias (BBC, New York Times, ProPublica) offrant des versions .onion pour contourner la censure
- Facebook (facebookwkhpilnemxj7asaniu7vnjjbiltxjqhye3mhbshg7kx5tfyd.onion) pour les utilisateurs dans des pays où le réseau est bloqué
- SecureDrop, plateforme pour lanceurs d'alerte utilisée par de nombreux médias
- ProtonMail, DuckDuckGo, et d'autres services de vie privée

**Cas d'usage légitimes de Tor**

- **Journalisme et protection des sources** : communiquer avec des sources sensibles sans risquer leur identification.
- **Militantisme et dissidence** : contourner la censure dans les régimes autoritaires.
- **Recherche sensible** : enquêter sur des sujets délicats sans laisser de traces.
- **Vie privée maximale** : pour ceux qui refusent catégoriquement la surveillance de masse.
- **Accès aux services bloqués** : dans les pays où certains sites sont censurés.

**Limitations et précautions**

Tor n'est pas une solution magique :

- **Vitesse réduite** : le trafic passe par au moins trois serveurs, ce qui ralentit considérablement la navigation.
- **Nœuds de sortie malveillants** : le dernier nœud voit votre trafic en clair (si vous n'utilisez pas HTTPS). N'entrez jamais d'informations sensibles sur un site HTTP via Tor.
- **Corrélation de trafic** : un adversaire puissant contrôlant à la fois le nœud d'entrée et de sortie pourrait théoriquement corréler le trafic pour vous identifier.
- **Fingerprinting** : si vous vous connectez à vos comptes personnels via Tor, vous révélez votre identité.
- **Attention aux téléchargements** : les fichiers PDF ou documents peuvent contenir du code qui se connecte directement à Internet, contournant Tor.

**Bonnes pratiques avec Tor**

1. Utilisez toujours HTTPS (Tor Browser active HTTPS-Only par défaut).
2. Ne maximisez pas la fenêtre du navigateur (cela révèle votre résolution d'écran).
3. N'installez pas d'extensions supplémentaires (elles peuvent compromettre l'anonymat).
4. Ne vous connectez pas à vos comptes personnels sauf si c'est absolument nécessaire.
5. Utilisez des pseudonymes et des identités séparées pour vos activités sur Tor.
6. Ne téléchargez pas de fichiers sauf si vous savez exactement ce que vous faites.

**Autres réseaux anonymes**

- **I2P (Invisible Internet Project)** : réseau anonyme similaire à Tor mais avec une architecture différente, optimisé pour les communications internes au réseau plutôt que pour accéder à l'Internet "clair".
- **Freenet** : réseau pair-à-pair décentralisé pour le stockage et la publication de contenu résistant à la censure.

Ces réseaux sont plus techniques et moins accessibles que Tor, réservés à des cas d'usage spécifiques.

### Exercices pratiques

La théorie est essentielle, mais la pratique est indispensable. Voici cinq exercices concrets pour mettre en application ce que vous venez d'apprendre. Consacrez-y le temps nécessaire : votre sécurité en ligne en dépend.

**Exercice 1 : Installation et configuration d'un bloqueur de publicités et trackers**

Objectif : protéger votre navigateur contre les publicités intrusives et le tracking.

Étapes :
1. Installez uBlock Origin sur votre navigateur principal (disponible pour Firefox, Chrome, Edge, Safari).
2. Ouvrez le tableau de bord de uBlock Origin (icône de l'extension → engrenage).
3. Dans l'onglet "Listes de filtres", activez les listes suivantes :
   - Toutes les listes "Publicités"
   - Toutes les listes "Vie privée"
   - "Malware domains"
   - Les listes régionales correspondant à votre langue/pays
4. Cliquez sur "Appliquer les modifications" puis "Vider tous les caches".
5. Visitez un site d'information connu pour ses nombreuses publicités et observez la différence.
6. Utilisez l'outil "Sélecteur" (icône de pipette) pour bloquer manuellement des éléments gênants sur une page.
7. Installez également Privacy Badger et observez comment il complète uBlock Origin.

Évaluation : après une semaine d'utilisation, consultez les statistiques de uBlock Origin (tableau de bord → onglet "Statistiques"). Combien de requêtes ont été bloquées ? Quel pourcentage de votre trafic représentait du tracking ?

**Exercice 2 : Audit de votre empreinte numérique avec outils de fingerprinting**

Objectif : comprendre à quel point votre navigateur est identifiable.

Étapes :
1. Visitez https://coveryourtracks.eff.org/ avec votre navigateur habituel.
2. Cliquez sur "Test your browser" et analysez les résultats.
3. Notez votre score : votre navigateur est-il unique ? Combien de trackers ont été détectés ?
4. Installez maintenant les extensions recommandées (uBlock Origin, Privacy Badger) et recommencez le test.
5. Comparez les résultats : votre empreinte a-t-elle changé ?
6. Testez avec un autre navigateur (Firefox avec protection renforcée, Brave, Tor Browser) et comparez.
7. Visitez https://browserleaks.com/ pour un audit plus approfondi :
   - Testez les fuites WebRTC
   - Vérifiez les informations Canvas
   - Examinez les polices détectables
8. Documentez vos observations : quelles informations votre navigateur révèle-t-il ?

Réflexion : aucune configuration ne vous rendra parfaitement anonyme (Tor Browser s'en approche mais au prix de la commodité). L'objectif est de rendre le tracking suffisamment difficile pour décourager la plupart des pisteurs.

**Exercice 3 : Configuration optimale de votre navigateur principal**

Objectif : durcir votre navigateur quotidien pour un équilibre vie privée/utilisabilité.

Pour Firefox (recommandé) :
1. Ouvrez les paramètres → Vie privée et sécurité.
2. Protection renforcée contre le pistage : choisissez "Strict".
3. Cookies et données de sites : cochez "Supprimer les cookies et les données de sites à la fermeture de Firefox".
4. Historique : choisissez "Ne jamais se souvenir de l'historique" ou configurez "Utiliser les paramètres personnalisés pour l'historique" avec suppression à la fermeture.
5. Permissions : révisez et restreignez les permissions (localisation, caméra, microphone, notifications).
6. Sécurité : activez "Bloquer les contenus dangereux et trompeurs".
7. DNS over HTTPS : activez-le avec un fournisseur de confiance (Cloudflare ou NextDNS).
8. Tapez `about:config` dans la barre d'adresse et acceptez le risque.
9. Recherchez `privacy.resistFingerprinting` et mettez-le à `true`.
10. Recherchez `webgl.disabled` et mettez-le à `true` (attention : cela peut casser certains sites).

Pour Brave :
1. Ouvrez les paramètres → Shields.
2. Bloquez les trackers et publicités : "Agressif".
3. Bloquez les cookies tiers.
4. Bloquez le fingerprinting : "Strict".
5. Désactivez Brave Rewards si vous ne l'utilisez pas.
6. Désactivez la télémétrie dans les paramètres de confidentialité.

Pour Chrome (si vous devez l'utiliser) :
1. Paramètres → Confidentialité et sécurité.
2. Cookies tiers : bloqués.
3. "Envoyer une requête 'Ne pas me pister'" : activé.
4. Sécurité : protection renforcée activée.
5. Désactivez la synchronisation si vous ne faites pas confiance à Google.
6. Utilisez les extensions recommandées (uBlock Origin, Privacy Badger).

Évaluation : après configuration, refaites l'exercice 2 (audit de fingerprinting) et comparez les résultats avant/après.

**Exercice 4 : Test de différents moteurs de recherche et comparaison des résultats**

Objectif : trouver le moteur de recherche privé qui correspond à vos besoins.

Étapes :
1. Choisissez 5 requêtes de test couvrant différents cas d'usage :
   - Une requête factuelle simple (ex: "capitale Australie")
   - Une requête technique (ex: "comment configurer firewall Linux")
   - Une requête actualité (ex: événement récent)
   - Une requête locale (ex: "restaurant italien [votre ville]")
   - Une requête shopping (ex: "meilleur laptop 2026 avis")

2. Testez chaque requête sur :
   - Google (pour référence)
   - DuckDuckGo
   - Startpage
   - Qwant
   - Brave Search

3. Pour chaque moteur, évaluez :
   - Pertinence du premier résultat (0-5)
   - Qualité globale de la première page (0-5)
   - Présence de publicités intrusives (oui/non)
   - Fonctionnalités utiles (réponses instantanées, filtres, etc.)

4. Créez un tableau comparatif avec vos notes.

5. Définissez votre moteur par défaut dans votre navigateur et testez-le pendant une semaine complète.

6. Après une semaine, évaluez : le moteur alternatif a-t-il répondu à tous vos besoins ? Avez-vous dû revenir à Google ? Dans quels cas ?

Conclusion : identifiez le moteur qui offre le meilleur compromis pour votre usage personnel. Configurez des raccourcis pour les moteurs alternatifs (!g pour Google via DuckDuckGo quand nécessaire).

**Exercice 5 : Évaluation et choix d'un service VPN adapté à vos besoins**

Objectif : sélectionner un VPN de confiance correspondant à votre modèle de menace.

Étapes :
1. Définissez votre modèle de menace :
   - Voulez-vous masquer votre trafic à votre FAI ?
   - Voulez-vous contourner la géo-restriction ?
   - Voulez-vous vous protéger sur les Wi-Fi publics ?
   - Avez-vous besoin d'anonymat (utilisez Tor plutôt qu'un VPN) ?

2. Recherchez et comparez 3 fournisseurs VPN en évaluant :
   - Juridiction et politique de confidentialité
   - Résultats d'audits indépendants (cherchez "audit" sur leur site)
   - Protocoles supportés (WireGuard, OpenVPN)
   - Politique de logs vérifiée
   - Transparence (rapports de transparence, mandats reçus)
   - Performance (testez avec les essais gratuits ou garanties de remboursement)
   - Prix (méfiez-vous des VPN "gratuits" : ils monétisent vos données)

3. Critères éliminatoires :
   - VPN basé dans un pays "Five Eyes" sans audit récent
   - VPN avec historique de vente de données utilisateurs
   - VPN "gratuit" sans modèle économique clair
   - VPN avec publicités agressives et promesses irréalistes

4. Sélectionnez 2 fournisseurs finalistes et testez-les pendant une semaine chacun :
   - Installez le client sur vos appareils
   - Testez la vitesse avec et sans VPN (utilisez speedtest.net)
   - Vérifiez les fuites DNS sur https://ipleak.net/
   - Testez la fonction kill switch (déconnectez-vous du VPN pendant un téléchargement)
   - Évaluez la facilité d'utilisation

5. Faites votre choix final et configurez le VPN :
   - Activez le kill switch
   - Activez la protection contre les fuites DNS
   - Configurez le VPN pour se connecter automatiquement au démarrage
   - Créez des règles pour les réseaux de confiance (votre domicile) où le VPN peut se désactiver

6. Documentez votre configuration et testez régulièrement que le VPN fonctionne correctement.

**Conclusion du chapitre**

La navigation web sécurisée n'est pas une destination mais un voyage continu. Les menaces évoluent, les techniques de tracking se perfectionnent, et vos besoins changent. Ce que vous avez appris dans ce chapitre constitue une base solide, mais vous devrez rester vigilant et adapter vos pratiques au fil du temps.

Retenez ces principes fondamentaux :
- HTTPS est nécessaire mais non suffisant
- Les extensions comme uBlock Origin et Privacy Badger sont votre première ligne de défense
- Le choix du navigateur (Firefox, Brave, ou Tor selon le contexte) est crucial
- Les moteurs de recherche privés existent et fonctionnent bien
- Un VPN de confiance protège votre trafic, surtout sur les réseaux non fiables
- Tor offre l'anonymat maximal pour les cas sensibles

Dans le chapitre suivant, nous aborderons le chiffrement de vos données sensibles, complétant ainsi votre arsenal pour protéger non seulement vos communications mais aussi vos fichiers les plus précieux.

## Chapitre 16 — Grille d'audit des trocs

Jusqu'ici, j'ai construit les concepts : les cinq monnaies, la grammaire du troc, les trocs invisibles, l'anatomie du déséquilibre, la dépendance toxique, les angles morts. Les concepts, c'est bien. Mais un leader qui referme ce livre demain matin a besoin d'autre chose : d'un instrument. Quelque chose qu'il puisse poser sur la table, remplir, montrer à quelqu'un, et qui lui réponde une seule chose honnête — *où est-ce que le pendule en est, là, maintenant, dans cette relation, dans cette équipe ?*

C'est la promesse pratique de ce livre : donner un outil de diagnostic complet, applicable à soi, à une relation bilatérale ou à une équipe entière. Ce chapitre est cet outil. La grille d'audit des trocs est l'objet le plus concret que je propose dans ces pages, et je vais en décrire l'architecture, la notation, les seuils d'alerte, un cas commenté, le rythme d'usage, et — tout aussi important — ses limites. Un instrument dont on ne dit pas les limites est un instrument dangereux : il finit toujours par mesurer ce qu'on avait envie de trouver.

Rappelons l'usage avant d'entrer dans le détail. L'audit ne juge pas les personnes. Il observe ce qui circule. La différence est fondamentale. Jugeer une personne, c'est conclure sur son caractère ; auditer un troc, c'est décrire un flux : qui donne, qui reçoit, à quelle intensité, depuis quand. On peut être un manager compétent et laisser mourir la monnaie de l'attention dans son équipe. On peut être une équipe brillante et vivre dans un excès de statut qui la vide de son sens. La grille ne dit pas « vous êtes mauvais ». Elle dit : « ici, le pendule est penché ; ici, il est figé ; ici, il oscille bien. »

---

### Architecture de la grille : 5 monnaies × 4 états du pendule

La grille est une matrice. Cinq lignes, quatre colonnes. Vingt cases. Pas une de plus.

**Les cinq lignes sont les cinq monnaies du leadership** que j'ai présentées au chapitre 3. Je les reprends ici en une phrase chacune, pour que ce chapitre reste lisible seul :

1. **Les ressources** — temps, budgets, tâches, décisions, informations, accès aux leviers. C'est la monnaie la plus visible, celle que les organisations savent compter.
2. **L'attention** — écoute réelle, présence, disponibilité, la capacité à tenir une conversation sans regarder l'écran. C'est la monnaie la plus fragile : elle ne se stocke pas.
3. **La reconnaissance** — nommer ce que la personne a fait, attribuer le mérite au bon endroit, dire le geste précis plutôt que le générique « bien joué ».
4. **Le statut** — visibilité, prestige, représentation, accès aux cercles, la part d'image et de position accordée à quelqu'un ou à un collectif.
5. **Le sens** — la direction, la cohérence, la réponse répétée à la question « pourquoi ce travail, et pourquoi maintenant ». La monnaie souveraine, celle dont je dirai tout au chapitre 19.

Cinq monnaies, car cinq suffisent à couvrir ce qui circule réellement entre un leader et ceux qu'il accompagne. Ajoutez une sixième et vous aurez une redite déguisée ; retirez-en une et vous laisserez une zone d'ombre — en général l'attention, la première qu'on sacrifie.

**Les quatre colonnes sont les quatre états du pendule.** Ce sont les états physiques du mouvement, transposés dans la vie relationnelle :

- **L'excès** : le pendule penche trop d'un côté. Le flux existe, il est même abondant — mais il déborde, il étouffe, il crée de la dette ou de la dépendance. C'est l'état du « trop ».
- **L'équilibre** : le pendule oscille. Il va, il revient. Le donner et le recevoir alternent dans les deux sens, sur une période raisonnable. C'est l'état vivant — jamais parfait, toujours en mouvement.
- **Le déficit** : le pendule oscille à peine. Le flux existe, mais il est ténu, irrégulier, insuffisant au regard du besoin. C'est l'état du « pas assez ».
- **La stase** : le pendule s'est arrêté. Il n'y a plus de flux du tout. Plus d'entretien, plus de reconnaissance, plus de décision partagée, plus de « pourquoi » annoncé. Ce n'est pas un déséquilibre : c'est une cessation d'échange. C'est l'état le plus grave, et le plus souvent invisible, parce que le silence ressemble à la paix tant qu'on n'a pas appris à l'écouter.

Pourquoi quatre ? Parce que trois — trop, juste, pas assez — confondent deux réalités très différentes : un flux faible et un flux absent. Un déficit appelle un réglage ; une stase appelle une relance. Quant à l'excès, il est le cinquième temps que tout le monde oublie : on auditte toujours ce qui manque, presque jamais ce qui étouffe. La colonne « excès » existe pour cela.

**La grille se lit ligne par ligne, jamais case par case.** On choisit pour chaque monnaie l'état qui décrit la réalité, on l'indice, on note le sens du flux, on justifie. La justification occupe toujours plus de place que la note : la note est un raccourci, la justification est le diagnostic.

Voici le modèle vierge :

| Monnaie | Excès (+) | Équilibre (0) | Déficit (−) | Stase (∅) | Indice | Sens du flux | Justification (un fait, une phrase) |
|---|---|---|---|---|---|---|---|
| Ressources | | | | | | | |
| Attention | | | | | | | |
| Reconnaissance | | | | | | | |
| Statut | | | | | | | |
| Sens | | | | | | | |

Trois marges accompagnent la matrice, et elles ne sont pas décoratives :

- **Le sens du flux** — qui donne, qui reçoit. Une flèche suffit : → (le leader ou l'organisation donne vers l'équipe), ← (l'équipe donne vers le leader), ↔ (circulation dans les deux sens), ∅ (aucun flux). Sans cette marge, vous saurez *combien* mais pas *dans quel sens* le pendule penche, et le diagnostic reste incomplet.
- **L'indice** — l'intensité de l'état, détaillée à la section suivante.
- **L'indice de confiance** — sur trois niveaux : **O** pour observation directe (un fait que j'ai vu ou enregistré), **R** pour récit (quelqu'un me l'a dit), **I** pour inférence (je le déduis). Ce petit signe en marge change tout : il vous dit sur quelle ligne vous êtes solide et sur laquelle vous rêvez.

### Notation : de « trop » à « pas assez », avec justification qualitative

L'échelle va de −2 à +2. Cinq crans, quatre états.

- **+2 — excès avéré.** Le flux est si abondant qu'il produit l'effet inverse de celui recherché : il étouffe, infantilise, crée une dette impossible à rembourser, ou dévore le temps qu'il prétend servir.
- **+1 — dérive d'excès.** Le flux est généreux mais commence à pencher. On est encore sauvable par un simple réglage.
- **0 — équilibre oscillant.** Le pendule va et vient. Ni parfait ni figé : vivant. Ne notez jamais 0 par confort. Un 0 doit être *justifié* comme un autre.
- **−1 — déficit.** Le flux existe mais il est insuffisant, irrégulier, ou systématiquement repoussé. On sent le manque plus qu'on ne le mesure : il crée de l'agacement discret plutôt que de l'urgence.
- **−2 — déficit sévère.** Le manque est criant, documenté, et commence à produire ses effets : turnover, désengagement, réunions vidées de leur sens, conflits qui reparaissent toujours au même endroit.
- **∅ — stase.** Le flux est nul ou si ténu qu'il revient au même. Le pendule est immobile. La stase n'entre pas dans l'échelle numérique : on la note avec le symbole ∅, et on la compte à part, car elle relève d'un autre registre que l'intensité. Un déficit est une amplitude ; une stase est une absence.

**La règle de la justification qualitative.** Une case remplie sans justification qualitative est une case non remplie. Pourquoi ? Parce que la note seule ment par omission : elle donne l'impression d'un état objectif alors qu'elle n'est qu'un résumé d'opinion. La justification oblige à trois choses.

D'abord, à citer **un fait**, pas une impression. Non pas « il n'y a pas assez d'attention », mais « sur les six derniers entretiens mensuels, trois ont été déplacés puis annulés ». Ensuite, à dater le fait : « depuis la réorganisation de mars ». Enfin, à nommer **l'effet observable** : « les collaborateurs cessent de porter des sujets qui exigent de l'écoute ».

Une justification correcte tient en une phrase, au format : *fait + date + effet*. Cette rigueur a un effet secondaire précieux : elle vous empêche d'auditer dans l'affect. Quand vous cherchez le fait, la colère retombe et le diagnostic se précise.

**Deux conventions de lecture.** Un indice est toujours relatif à une période — je recommande douze mois glissants, sauf indication contraire. Et une note ne se compare jamais entre personnes : elle se compare entre colonnes pour une même monnaie, et entre lignes pour un même état. Vous n'auditez pas Marie et Paul ; vous auditez la relation de Marie et de Paul avec le collectif.

### Seuils d'alerte : quand l'audit doit déclencher une action

Une grille remplie sans règle de déclenchement reste un exercice d'écriture. Les seuils sont ce qui transforme l'audit en décision.

**Seuil 1 — La stase, priorité absolue.** Dès qu'une case porte ∅, l'audit déclenche une action, sans exception et sans attendre l'audit suivant. La stase signifie que quelque chose a cessé d'être échangé, et les échanges cessés ne repartent jamais seuls. Action attendue sous quinze jours : reprendre le flux, même minuscule — un entretien non déplaçé, une décision annoncée, un « pourquoi » redit.

**Seuil 2 — Le seuil de déséquilibre.** Si, pour une même monnaie, l'écart entre le sens du flux opposé dépasse deux points — par exemple des ressources à +2 dans un sens et de la reconnaissance à −2 dans l'autre —, le déséquilibre est structurel. On ne le règle pas par un ajustement ponctuel mais par une négociation explicite de réciprocité. C'est ici que le contrat psychologique du chapitre 9 redevient l'outil central.

**Seuil 3 — Le seuil de concentration.** Si trois monnaies ou plus se trouvent en déficit ou en stase simultanément, le problème n'est plus local : il est systémique. Trois lignes faibles sur cinq, c'est le signal d'un leader ou d'une organisation qui a cessé de troquer en général — souvent parce qu'il est passé en mode contrôle ou en mode survie. Action attendue : une revue d'ensemble, pas cinq correctifs séparés.

**Seuil 4 — Le seuil d'excès.** Un indice +2 sur l'attention, le statut ou les ressources déclenche l'action au même titre qu'un déficit. L'excès ne se soigne pas par davantage d'autre chose, mais par un retrait organisé : rendre du temps, redistribuer de la visibilité, désengorger une décision. Beaucoup d'équipes « surmanagement » meurent d'un excès qu'elles prenaient pour du soin.

**Seuil 5 — Le seuil de confiance.** Si une case essentielle repose uniquement sur de l'inférence (I) et que son indice dépasse un palier d'alerte, l'audit déclenche non pas une action, mais une **vérification**. On ne pilote pas sur du déduit. Avant de corriger, on va regarder.

Ces seuils ne sont pas des verdicts automatiques. Ils indiquent *quand regarder*, pas *quoi faire*. Le « quoi faire » appartient au protocole de rééquilibrage en cinq mouvements du chapitre 17. Une grille qui prétendrait à elle seule prescrire la cure serait un livre de recettes déguisé en instrument de mesure.

### Cas d'école illustré : audit commenté d'une équipe fictive

Prenons une équipe fictive de huit personnes, un manager en place depuis onze mois, en pleine transformation de son périmètre métier. Je nomme le manager Karim et l'équipe « Alpha ». Je remplis la grille comme je le ferais en vrai : à partir de faits, pas de sentiments.

| Monnaie | État | Indice | Sens | Justification |
|---|---|---|---|---|
| Ressources | Excès | +1 | → | Décisions centralisées : sur les 24 dernières décisions significatives, 19 ont été prises par Karim seul, souvent de bonnes décisions, mais l'équipe n'a plus de prise. Effet : trois membres attendent Karim pour des arbitrages qu'ils tranchaient avant. |
| Attention | Stase | ∅ | ↔ | Depuis la transformation, les entretiens individuels mensuels sont déplacés deux fois sur trois ; deux collaboratrices n'ont pas eu d'entretien depuis septembre. Effet : elles ont cessé de porter les sujets qui demandent de l'écoute. |
| Reconnaissance | Déficit | −1 | ← | Deux remerciements publics en six mois, tous génériques (« merci à toute l'équipe »). Personne ne sait quel travail de Karim est reconnu par sa hiérarchie. Effet : les contributions individuelles deviennent invisibles, donc cessent d'être répétées. |
| Statut | Équilibre | 0 | ↔ | Karim représente l'équipe en comité et remonte les prénoms ; l'équipe le sollicite comme porte-parole. Circulation jugée saine par quatre membres interrogés. |
| Sens | Déficit | −1 | → | Le « pourquoi » de la transformation n'a été redit qu'une fois, en janvier. Effet : deux membres interrogés formul

ent deux lectures contradictoires de la même transformation — signe qu'il n'y a plus de récit partagé.

**Lecture commentée.** La première chose qui saute aux yeux, c'est la stase sur l'attention. C'est la ligne qui déclenche l'action prioritaire selon le seuil 1 : Karim doit reprendre les entretiens individuels sous quinze jours, sans négociation de planning, sans nouveau format, sans outil. Le flux minimal suffit pour remettre le pendule en mouvement.

La deuxième chose, c'est le contraste entre deux lignes. Des ressources à +1 (excès de contrôle) et de la reconnaissance à −1 (déficit) : Karim concentre les décisions mais ne reçoit lui-même aucune reconnaissance visible de sa hiérarchie, et n'en redistribue presque aucune. C'est exactement le profil du leader en pression qui, faute d'être reconnu en amont, resserre le contrôle en aval. Le seuil 2 n'est pas atteint — l'écart n'est pas de deux points sur le même axe de flux — mais le schéma est lisible, et il oriente la conversation vers ce qui se passe *au-dessus* de Karim, pas seulement autour de lui.

La troisième chose, c'est le sens à −1 avec une justification datée : le « pourquoi » a été dit une fois, en janvier, et on est

maintenant en novembre. Onze mois sans redire la direction, c'est un déficit structurel et non un oubli conjoncturel. L'effet observé — deux lectures contradictoires de la même transformation — est classique : quand le leader cesse de répéter le sens, l'équipe le reconstruit elle-même, chacun à sa manière, et les récits divergent sans que personne ne se dispute ouvertement. Le seuil 3 n'est pas déclenché (deux lignes faibles, pas trois), mais le sens est précisément la monnaie dont la faiblesse se propage le plus vite aux autres : on ne donne pas de reconnaissance à un travail dont on a perdu le fil, on ne prête pas d'attention à une conversation dont on a oublié l'enjeu.

Enfin, une absence révélatrice : la confiance. Sur les cinq lignes, quatre reposent sur des observations directes (O) ou des récits (R), une seule sur une inférence (I) — la ligne « sens », où je déduis la divergence des récits de deux entretiens sans l'avoir encore vérifiée auprès des six autres membres. Le seuil 5 s'applique donc : avant de proposer quoi que ce soit à Karim sur le sens, je vais écouter les six autres. Peut-être que le récit existe et circule mieux que je ne le crois dans des espaces que je n'ai pas observés. La grille, dans ce cas, ne produit pas une action corrective mais une question posée au bon endroit.

**Ce que l'audit d'Alpha ne dit pas.** Il ne dit pas que Karim est un mauvais manager. Il dit que, onze mois après sa prise de poste, dans un contexte de transformation, son pendule s'est partiellement figé sur l'attention et penche du côté du contrôle sur les ressources. C'est une description, pas un jugement. La différence se voit dans la conversation qui suit : « Karim, voici ce que j'observe sur ce qui circule entre toi et ton équipe » ouvre une discussion ; « Karim, tu ne donnes pas assez d'attention à ton équipe » ouvre une défensive. La grille sert exactement à rendre la première conversation possible.

### Rythme d'audit : ponctuel, trimestriel, ou en continu

Une grille n'a de valeur que si elle est utilisée au bon rythme. Trop souvent, et elle devient un exercice administratif. Trop rarement, et elle perd toute capacité à détecter les inflexions. Trois rythmes coexistent, et ils ne se substituent pas.

**L'audit ponctuel** est déclenché par un événement. Prise de poste, réorganisation, départ clé, conflit ouvert, stagnation ressentie sans cause identifiée, fusion d'équipes. Il répond à une question urgente : *où en est le pendule, ici et maintenant, après le choc ?* Il se fait en une séance, seul ou à deux, et son rendu tient en une page. Son danger est de n'être appelé qu'aux mauvais moments — quand les dégâts sont déjà visibles — et de passer pour un audit de deuil plutôt que d'alerte. Son avantage est sa rapidité : en une heure, vous avez une carte.

**L'audit trimestriel** est le cœur du dispositif. Il reprend la grille complète, la met à jour, et surtout la compare à l'audit précédent. C'est dans la comparaison que réside la vraie valeur : une ligne passée de −1 à 0 est un progrès ; une ligne passée de 0 à ∅ est un signal d'alarme masqué par la moyenne. Le trimestre est la bonne échelle parce que les échanges relationnels ne bougent ni à la semaine ni à l'année : les effets de sens, de reconnaissance et d'attention demandent quelques mois pour se former et quelques mois pour se défaire. Un rythme plus court crée de la volatilité de notation ; un rythme plus long vous fait rater le moment où un flux devient une stase.

**L'audit en continu** ne remplit pas la grille. Il la rend familière. Il consiste à garder les cinq monnaies et les quatre états en tête au quotidien, sans les noter : à chaque réunion, à chaque entretien, à chaque décision, se poser la question de cinq secondes — *qu'est-ce qui circule là, et dans quel sens ?* — et laisser cette perception alimenter le prochain audit trimestriel. C'est la version mentale de l'instrument. Elle ne produit pas de rapport, mais elle produit quelque chose de plus précieux : un leader qui voit venir le figement du pendule avant que la grille ne le confirme.

**Qui remplit la grille ?** Trois configurations, selon le niveau de confiance existant.

Première configuration, **l'audit solo** : le leader remplit la grille sur sa propre équipe. Utile, rapide, honnête — à condition d'être relu par un pair ou un mentor pour contrer les angles morts du chapitre 15.

Deuxième configuration, **l'audit croisé** : deux personnes — par exemple un manager et un pair — remplissent chacune la grille sur la même équipe, puis comparent. Les écarts de notation deviennent alors le matériau de la conversation, souvent plus éclairant que le score moyen.

Troisième configuration, **l'audit partagé** : l'équipe remplit la grille collectivement sur la relation qu'elle entretient avec son manager ou avec elle-même. C'est la version la plus puissante et la plus risquée : puissante parce qu'elle multiplie les points de vue, risquée parce qu'elle expose des perceptions. Elle n'a de sens que dans un cadre sécurisé, avec des règles claires sur l'anonymat des justifications et l'usage qui sera fait des écarts. Les ateliers de mise à nu des réciprocités du chapitre 12 sont le bon moment pour cette configuration.

Quelle que soit la configuration, une règle ne se négocie pas : **l'audit n'est pas un outil d'évaluation individuelle.** S'il est rattaché à une revue de performance, il cessera très vite de dire la vérité, parce que dire la vérité sur un déséquilibre deviendra risqué. La grille vit dans un espace séparé de toute notation hiérarchique, ou elle meurt.

### Limite de l'outil : ce que la grille ne mesure pas

Un instrument honnête commence par décrire son propre périmètre. La grille des trocs mesure bien une chose : **l'état perçu des échanges de valeur entre un leader et son environnement proche, sur une période donnée, avec un degré de confiance explicite.** C'est déjà beaucoup. Ce n'est pas tout, et il serait dangereux de le croire.

**Elle ne mesure pas les personnes.** Elle décrit des flux, pas des caractères. Une équipe qui sort un audit défavorable sur l'attention n'est pas une équipe « mal accompagnée » ; c'est une équipe où la circulation d'attention s'est réduite sur la période. La confusion entre l'état d'un flux et la qualité d'une personne est la première dérive possible de l'outil, et la plus fréquente quand l'audit est capté par une logique de pouvoir.

**Elle ne mesure pas la qualité intrinsèque du contenu échangé.** Dire « Karim donne du sens à son équipe trois fois par semaine » ne dit rien de la justesse de ce sens. Un récit de direction parfaitement répété peut être parfaitement faux. La grille observe la circulation, pas la véracité. C'est au leader de vérifier, par d'autres canaux, que ce qui circule est digne de circuler.

**Elle ne mesure pas les trocs qui se jouent hors de son champ.** Un collaborateur peut recevoir tout le sens et toute la reconnaissance du monde de son manager et rester profondément déséquilibré parce que, latéralement, ses pairs lui prennent du temps sans jamais rien rendre. La grille, telle que je l'ai conçue, porte sur l'axe leader–équipe. Elle peut être déclinée sur d'autres axes — pairs, pairs–manager, équipe–hiérarchie — mais chaque déclinaison est un audit distinct, et leur somme n'est pas automatiquement le tableau complet.

**Elle ne mesure pas le temps de latence.** Certains effets relationnels mettent des trimestres à apparaître. Un déficit de reconnaissance peut rester sans effet visible pendant six mois, puis se traduire par trois démissions rapprochées. La grille capte l'état actuel, pas la traînée qu'il laisse dans le futur. C'est pourquoi la comparaison entre audits successifs est plus informative que n'importe quel instantané.

**Elle ne mesure pas ce qui ne relève pas de l'échange.** Il existe, dans toute relation de leadership, une part de don gratuit — de la bienveillance sans contrepartie, de la patience qui ne sera jamais rendue, du risque pris pour quelqu'un sans attente de retour. Réduire toute la relation au troc, c'est appauvrir ce qui fait la dignité du leadership. J'ai choisi de construire un livre sur l'échange parce qu'il est sous-explicité et fécond, non parce qu'il explique tout. Le pendule décrit une dimension de la réalité relationnelle ; il n'en est pas la totalité. Ceux qui feront de la grille une grille totale de l'existence relationnelle la détruiront en la surchargeant.

**Enfin, elle ne remplace pas le jugement.** La grille informe le jugement ; elle ne s'y substitue pas. Il arrive qu'un indice technique dise équilibre alors que le ressenti de l'équipe crie stase — et que le ressenti ait raison, parce que les faits que vous avez collectés sont les faits qu'on vous a montrés. La grille est un garde-fou contre l'impressionnisme, pas un garde-fou contre l'aveuglement. Pour cela, il lui faut toujours être complétée par des conversations, et surtout par les contre-audits des personnes concernées — ce que je détaillerai dans les exercices à la fin de ce chapitre.

Ces limites ne disqualifient pas l'outil. Elles le rendent utilisable. Un instrument qui connaîtrait ses propres angles morts est plus digne de confiance qu'un instrument qu'on présenterait comme omniscient.

### Ce que la grille permet, une fois maîtrisée

Revenons un instant à ce qu'elle offre, une fois assumées ses limites.

Elle offre **un langage commun**. Là où une équipe disait « on n'est pas bien », elle dira « la reconnaissance est en déficit et la stase est sur l'attention ». La première phrase est une plainte ; la seconde est une information actionnable.

Elle offre **une comparabilité dans le temps**. Vous saurez, dans six mois, si votre passage à l'action a déplé une ligne ou si le pendule s'est figé ailleurs. Sans grille, l'amélioration reste une impression ; avec elle, elle devient une trajectoire.

Elle offre **une porte d'entrée pour des conversations difficiles**. Dire à un pair « je pense que tu ne donnes pas assez d'attention à ton équipe » provoque de la défense. Dire « voici une grille que j'ai remplie sur mon propre audit, et voici les deux lignes où je suis en stase, veux-tu la relire et me dire ce que tu observes ? » ouvre une porte.

Elle offre enfin **une discipline de l'attention**. Remplir la grille trimestriellement, c'est s'obliger, quatre fois par an, à regarder ce qui circule vraiment plutôt que ce qu'on croit circuler. Cette discipline, à elle seule, modifie le comportement du leader, indépendamment des actions correctives qu'elle déclenche.

### Exercices

Les deux exercices qui suivent sont le complément nécessaire de ce chapitre. Une grille non remplie n'est qu'un joli schéma. Ces exercices font passer l'outil du statut de modèle au statut d'instrument vécu.

**Exercice 1 — Réaliser un audit complet**

Choisissez une relation ou une équipe sur laquelle vous avez suffisamment de matière pour observer des flux réels. Remplissez la grille complète, cinq lignes, quatre colonnes. Pour chaque ligne, appliquez les trois exigences de notation : un indice (de −2 à +2, ou ∅), un sens du flux, et une justification sous la forme *fait + date + effet*. Ajoutez en marge l'indice de confiance (O, R ou I).

Une fois la grille remplie, identifiez les seuils déclenchés selon les cinq règles du chapitre. Puis rédigez un rapport de deux pages, structuré en trois parties : (1) l'état du pendule, ligne par ligne, sans commentaire de personne ; (2) les seuils d'alerte déclenchés et leur signification ; (3) **trois recommandations prioritaires**, classées par urgence, chacune formulée comme une action précise avec un horizon de temps. Une recommandation prioritaire n'est pas une intention (« donner plus d'attention ») ; c'est un geste daté et identifiable (« rétablir l'entretien individuel mensuel, non déplaçable, à partir du mois prochain, pour les huit membres »). Le rapport tient en deux pages parce qu'un diagnostic qui déborde deux pages n'est plus un diagnostic : c'est un dossier.

**Exercice 2 — Partager l'audit et recueillir les contre-audits**

Repérez, dans votre rapport, les éléments non sensibles — les lignes concernées, les effets observés, les seuils déclenchés, les recommandations — et préparez une version éditable de l'audit, sans noms propres ni citations attribuables, ni aucun détail qui permettrait de reconnaître une personne à travers un fait particulier. Partagez cette version avec les personnes concernées, en expliquant clairement le cadre : ce n'est pas une évaluation, c'est une perception à confronter, et leur rôle est de la contredire s'ils la contredisent.

Demandez ensuite explicitement un **contre-audit** : quelle ligne décririez-vous autrement ? Quel indice changeriez-vous ? Quel fait m'aurait échappé et qui modifierait le diagnostic ? Recevez ces contre-audits sans les défendre, notez-les, et produisez une seconde version de la grille qui intègre — ou documente le refus d'intégrer — chaque modification proposée. La comparaison entre la version 1 et la version 2 est souvent plus instructive que la grille initiale : elle montre où votre perception était juste, où elle était partielle, et surtout où existait un angle mort que seul le regard extérieur pouvait signaler.

Ce n'est qu'une fois ces deux exercices menés que la grille cesse d'être un schéma de chapitre pour devenir un instrument que vous possédez. Et c'est à ce moment précis qu'elle commence à produire ses effets les plus utiles — non pas en vous donnant raison, mais en vous montrant, trimestre après trimestre, où le pendule a encore besoin d'être relancé.
